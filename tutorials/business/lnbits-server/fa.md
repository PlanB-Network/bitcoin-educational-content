LNbits یک برنامه وب Interface منبع باز است که هر بک‌اند لایتنینگ (LND، Core Lightning، PHOENIXD) را به یک پلتفرم خدمات کامل تبدیل می‌کند. این راه‌حل خودمیزبان به شما امکان می‌دهد تا چندین پورتفولیو لایتنینگ را به صورت مجزا مدیریت کنید، نقاط فروش را مستقر کنید، سیستم‌های اهدایی یا خدمات صورتحساب ایجاد کنید، در حالی که کنترل کامل بر روی وجوه خود را حفظ می‌کنید.



این آموزش دو روش نصب را پوشش می‌دهد: **VPS Ubuntu با PHOENIXD** (راه‌حل سبک بدون یک نود کامل Bitcoin) و **Umbrel** (یکپارچه‌سازی با نود LND موجود شما). برخلاف آموزش کلی LNbits شبکه Plan B، که مفاهیم و افزونه‌ها را پوشش می‌دهد، این راهنما بر روی مراحل نصب فنی گام‌به‌گام تمرکز دارد.



## LNbits چیست؟



LNbits یک سیستم حسابداری Lightning است که با استفاده از Python (FastAPI) توسعه یافته و به یک بک‌اند موجود (LND، Core Lightning، PHOENIXD) متصل می‌شود. برخلاف نودهای سنتی Lightning، LNbits یک Interface قابل دسترسی ارائه می‌دهد که به شما امکان می‌دهد چندین پورتفولیو مجزا با کلیدهای API مخصوص به خود را مدیریت کنید. شما می‌توانید زیرحساب‌هایی برای خانواده، کارمندان یا پروژه‌های خود ایجاد کنید، بدون اینکه به آن‌ها دسترسی به تمام وجوه خود بدهید.



معماری جدا شده اطلاعات را در SQLite (پیش‌فرض) یا PostgreSQL (تولید) ذخیره می‌کند، در حالی که مدیریت وجوه توسط بک‌اند لایتنینگ شما انجام می‌شود. این جداسازی قابلیت حمل را تضمین می‌کند: شما می‌توانید از PHOENIXD به LND مهاجرت کنید بدون اینکه داده‌های کاربری خود را از دست بدهید.



## ویژگی‌های کلیدی



LNbits یک **سیستم افزونه** چندمنظوره ارائه می‌دهد: TPoS (نقطه فروش)، Paywall (کسب درآمد از محتوا)، Events (بلیط‌فروشی)، LndHub (سرور برای BlueWallet)، Bolt Cards (پرداخت‌های NFC)، Split Payments (توزیع خودکار)، و User Manager (مدیریت کاربران با احراز هویت).



**داشبورد** موجودی‌های لحظه‌ای، تاریخچه تراکنش‌ها و ابزارهای صورتحساب را نمایش می‌دهد. هر Wallet دارای یک URL منحصر به فرد است که شامل کلیدهای API آن می‌باشد و امکان دسترسی بدون ورود سنتی را فراهم می‌کند. سیستم کلید API سه‌سطحی** (مدیر، Invoice، فقط‌خواندنی) کنترل دقیق مجوزها برای یکپارچه‌سازی‌های امن را ارائه می‌دهد.



LNbits به صورت بومی **LNURL** (LNURL-pay، LNURL-Withdraw، LNURL-auth) را پیاده‌سازی می‌کند و از **Lightning Address** پشتیبانی می‌کند، که تضمین‌کننده سازگاری با کیف‌پول‌های مدرن Lightning و تسهیل‌کننده استقرار خدمات حرفه‌ای است.

## نصب بر روی Ubuntu VPS با PHOENIXD



### مرحله 1: ایمن‌سازی سرور VPS



**قبل از هرگونه نصب**، باید سرور VPS اوبونتو خود را مطابق با قوانین هنر ایمن کنید. این مرحله برای محافظت از زیرساخت و سرمایه‌های Lightning شما **حیاتی** است.



در اینجا یک راهنمای دقیق برای کمک به شما در شروع کار آمده است: **[پیکربندی اولیه سرور اوبونتو - راهنمای گام به گام](https://danielpcostas.dev/ubuntu-server-initial-configuration-a-step-by-step-guide/)** توسط دانیل پی. کوستاس.



این راهنما شامل پیکربندی کاربر، SSH امن، فایروال (UFW)، fail2ban، به‌روزرسانی‌های خودکار و روش‌های خوب امنیت سیستم است.



### مرحله 2: نصب PHOENIXD



پس از ایمن‌سازی سرور خود، باید PHOENIXD را نصب و پیکربندی کنید. شبکه Plan B یک آموزش کامل و اختصاصی ارائه می‌دهد که نصب، تولید seed و پیکربندی سرویس systemd را پوشش می‌دهد:



https://planb.academy/tutorials/node/lightning-network/phoenixd-beb86edd-f9c0-4bec-ad36-db234c88e7b1

هنگامی که PHOENIXD راه‌اندازی شد (با `./Phoenix-CLI getinfo` بررسی کنید)، **رمز عبور HTTP** را در `~/.Phoenix/Phoenix.conf` یادداشت کنید - برای اتصال LNbits به PHOENIXD به آن نیاز خواهید داشت.



### استقرار LNbits



نصب UV و کلون LNbits :


```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
git clone https://github.com/lnbits/lnbits.git && cd lnbits
uv sync --all-extras
```



پیکربندی بخش پشتی PHOENIXD:


```bash
cp .env.example .env && nano .env
```



به `.env` اضافه کنید :


```
LNBITS_BACKEND_WALLET_CLASS=PhoenixdWallet
PHOENIXD_API_ENDPOINT=http://127.0.0.1:9740
PHOENIXD_API_PASSWORD=<mot-de-passe-phoenix.conf>
```



با `uv run lnbits --host 0.0.0.0 --port 5000` تست کنید سپس یک سرویس systemd با `Wants=PHOENIXD.service` ایجاد کنید.



## راه‌اندازی اولیه و اولین استفاده



### فعال‌سازی SuperUser



فعال‌سازی مدیر Interface در `.env` :


```
LNBITS_ADMIN_UI=true
```



LNbits را مجدداً راه‌اندازی کنید (`sudo systemctl restart lnbits`) و شناسه SuperUser را بازیابی کنید:


```bash
cat ~/lnbits/data/.super_user
```



به `http://<IP-VPS>:5000/Wallet?usr=<SuperUserID>` برای پنل مدیریت بروید. منوی "سرور" به شما اجازه می‌دهد منابع مالی، افزونه‌ها و حساب‌های کاربری را پیکربندی کنید.



### ایجاد حساب کاربری امن



**مهم برای نمایش عمومی**: اگر شما در حال نمایش نمونه LNbits خود بر روی یک نام دامنه عمومی قابل دسترسی از اینترنت هستید، **بسیار مهم** است که ایجاد رایگان حساب‌های کاربری را غیرفعال کنید.



از بخش مدیریت SuperUser Interface، به "Settings" بروید و سپس به بخش "User Management" بروید. گزینه "Allow creation of new users" را پیدا خواهید کرد.



![Gestion des utilisateurs - Sécurité](assets/fr/17.webp)



**برای یک نمایشگاه عمومی با نام دامنه** :




- شما باید گزینه **"اجازه ایجاد کاربران جدید"** را غیرفعال کنید
- بدون این حفاظت، هر کسی در اینترنت می‌تواند یک حساب کاربری در نمونه شما ایجاد کند.
- یک مهاجم می‌تواند حساب‌هایی ایجاد کند و بدون اطلاع شما از نقدینگی LIGHTNING NODE شما استفاده کند.
- شما باید حساب‌های کاربری را به صورت دستی از Interface SuperUser ایجاد کنید.



**فقط برای استفاده محلی** :




- این گزینه کمتر حیاتی است اگر نمونه شما فقط به صورت محلی قابل دسترسی باشد (http://localhost:5000)
- با این حال، غیرفعال کردن این گزینه یک عمل ایمنی عمومی خوب است.



پس از پیکربندی، تنها مدیر SuperUser می‌تواند حساب‌های کاربری جدید را از طریق Interface "Users" ایجاد کند. این رویکرد کنترل کامل بر اینکه چه کسی می‌تواند به زیرساخت Lightning شما دسترسی داشته باشد و از وجوه شما استفاده کند را تضمین می‌کند.



### باز کردن کانال اول



PHOENIXD به‌طور خودکار کانال‌ها را از طریق نقدینگی خودکار مدیریت می‌کند. generate یک Invoice لایتنینگ از ~30,000 Sats از LNbits و پرداخت آن از یک Wallet دیگر. PHOENIXD به‌طور خودکار یک کانال به ACINQ باز می‌کند. هزینه باز کردن (~20-23k Sats) کسر می‌شود، و موجودی باقی‌مانده (~7-10k Sats) پس از تأیید On-Chain ظاهر می‌شود.



وضعیت را با `./Phoenix-CLI getinfo` بررسی کنید. سپس در نظر بگیرید که قابلیت نقدینگی خودکار را غیرفعال کنید (`auto-liquidity=off` در `Phoenix.conf`) تا کنترل بهتری بر روی باز شدن کانال‌ها داشته باشید.



### نمایش عمومی و HTTPS



**مهم**: استفاده از HTTPS برای نمایش عمومی الزامی است (امنیت کلید API + سازگاری LNURL). این مرحله را فقط برای استفاده محلی نادیده بگیرید.



**Caddy (توصیه‌شده)**: SSL خودکار. `sudo apt install -y caddy`، فایل `/etc/caddy/Caddyfile` را ویرایش کنید:


```
votre-domaine.com {
reverse_proxy 127.0.0.1:5000
}
```


راه‌اندازی مجدد: `sudo systemctl restart caddy`.



**Nginx** : کنترل بیشتر. نصب `nginx certbot python3-certbot-nginx`، ایجاد `/etc/nginx/sites-available/lnbits` :


```nginx
server {
listen 80;
server_name votre-domaine.com;
location / {
proxy_pass http://127.0.0.1:5000;
proxy_set_header Host $host;
proxy_set_header X-Forwarded-Proto $scheme;
}
}
```


فعال‌سازی: `sudo LN -s /etc/nginx/sites-available/lnbits /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl reload nginx && sudo certbot --nginx -d your-domain.com`



به `.env` اضافه کنید: `FORWARDED_ALLOW_IPS=*`

### پیکربندی اولیه SuperUser



در اولین راه‌اندازی، LNbits از شما می‌خواهد که حساب کاربری مدیر SuperUser را ایجاد کنید. یک نام کاربری وارد کنید و یک رمز عبور امن تنظیم کنید تا دسترسی به سیستم مدیریت Interface محافظت شود.



![Configuration SuperUser](assets/fr/03.webp)



**مهم**: این حساب کاربری SuperUser دارای تمامی امتیازات در نمونه LNbits شما است. یک رمز عبور قوی انتخاب کنید و آن را ایمن نگه دارید.



به محض اینکه یک حساب کاربری ایجاد کردید، به‌طور خودکار به ناحیه اصلی مدیریت Interface هدایت می‌شوید. Umbrel قبلاً LND را به عنوان منبع تأمین مالی شما تنظیم کرده است - تمام پرداخت‌های Lightning از طریق کانال‌های موجود شما انجام خواهد شد.



### دسترسی به مدیر Interface



در منوی سمت چپ، بر روی "Settings" کلیک کنید تا به پنل کامل مدیریت دسترسی پیدا کنید.



![Interface Settings](assets/fr/04.webp)



بخش "مدیریت کیف‌پول‌ها" اطلاعات کلیدی درباره پیکربندی شما را نمایش می‌دهد:




- منبع تأمین مالی** : LndBtcRestWallet (اتصال مستقیم به نود LND Umbrel شما)
- موجودی نود** : کل نقدینگی موجود در کانال‌های لایتنینگ شما
- موجودی LNbits**: وجوه اختصاص داده شده به سیستم LNbits (در ابتدا 0 Sats)



اکنون می‌توانید به‌طور مستقیم از نقدینگی نود Umbrel خود برای تمام کیف‌پول‌های LNbits که ایجاد می‌کنید، بهره‌برداری کنید. هیچ تنظیمات اضافی مورد نیاز نیست - LNbits در حال اجرا است.



### مدیریت کاربر



یکی از قدرتمندترین ویژگی‌های LNbits توانایی آن در ایجاد چندین کاربر مستقل است، هر کدام با احراز هویت رمز عبور و کیف پول‌های جداگانه. این معماری امکان استفاده از نقدینگی نود Umbrel شما را فراهم می‌کند در حالی که حساب‌های فرعی کاملاً جداگانه‌ای برای استفاده‌های مختلف ارائه می‌دهد: کسب‌وکار، خانواده، کارمندان، پروژه‌ها و غیره.



در منوی کناری، روی "Users" کلیک کنید تا به مدیریت کاربران دسترسی پیدا کنید. برای افزودن کاربر جدید روی "CREATE ACCOUNT" کلیک کنید.



![Gestion des utilisateurs](assets/fr/05.webp)



فرم ایجاد کاربر را پر کنید:




- نام کاربری**: نام کاربری ورود (مثال: "Satoshi")
- تنظیم رمز عبور**: این گزینه را فعال کنید تا یک رمز عبور احراز هویت تنظیم کنید
- رمز عبور** و **تکرار رمز عبور**: رمز عبور را برای این کاربر تنظیم کنید



![Création utilisateur satoshi](assets/fr/06.webp)



فیلدهای اختیاری (کلید عمومی Nostr، ایمیل، نام، نام خانوادگی) می‌توانند برای پیکربندی حداقلی خالی بمانند. برای تأیید روی "ایجاد حساب" کلیک کنید.



![Confirmation utilisateur créé](assets/fr/07.webp)



کاربر جدید شما اکنون با شناسه منحصربه‌فرد و نام کاربری خود در فهرست کاربران ظاهر می‌شود.

### مدیریت کاربر Wallet



اکنون که کاربر "Satoshi" ایجاد شده است، باید یک Wallet Lightning به او اختصاص دهید. بر روی آیکون Wallet (آیکون دوم) برای کاربر مربوطه کلیک کنید، سپس بر روی "CREATE NEW Wallet" کلیک کنید.



![Gestion des wallets](assets/fr/09.webp)



یک کادر محاوره‌ای از شما می‌خواهد که Wallet را نام‌گذاری کنید. یک نام توصیفی وارد کنید (مثلاً "Wallet از Satoshi") و ارز نمایش را انتخاب کنید (CUC, USD, EUR, etc.).



![Création wallet](assets/fr/10.webp)



روی "CREATE" کلیک کنید. LNbits بلافاصله یک Wallet Lightning کاربردی برای این کاربر ایجاد می‌کند.

اکنون دو کیف پول موجود را مشاهده می‌کنید: کیف پول پیش‌فرض Wallet "LNbits Wallet" که به‌طور خودکار ایجاد شده است و کیف پول جدید "Wallet Of Satoshi". برای ساده‌سازی تجربه کاربری، می‌توانید کیف پول پیش‌فرض Wallet را با کلیک بر روی آیکون حذف (سطل زباله قرمز) حذف کنید.

**مفهوم کلیدی**: تمام این کیف‌پول‌ها از نقدینگی جهانی نود Umbrel شما استفاده می‌کنند. شما برای هر Wallet کانال‌های لایتنینگ جدیدی ایجاد نمی‌کنید - LNbits به عنوان یک Layer حسابداری هوشمند عمل می‌کند که تخصیص وجوه را در زیرساخت لایتنینگ موجود شما مدیریت می‌کند. این قدرت سیستم چند-Wallet LNbits است.

- موجودی فعلی**: نمایش داده شده در Sats و به ارز انتخابی (CUC در این مثال)
- اقدامات اصلی**: "درخواست چسباندن" (چسباندن قبض برای پرداخت)، "ایجاد Invoice" (generate یک رسید)، آیکون QR (اسکن سریع)
- تاریخچه تراکنش** : لیست کامل تمامی پرداخت‌ها و دریافت‌ها
- پنل سمت راست**: گزینه‌های پیکربندی و دسترسی



### دسترسی موبایل Wallet



پنل سمت راست یک ویژگی بسیار کاربردی ارائه می‌دهد: دسترسی موبایل به Wallet. بخش "دسترسی موبایل" را باز کنید تا گزینه‌های موجود را کشف کنید.



![Mobile Access](assets/fr/15.webp)



LNbits چندین روش برای استفاده از این Wallet بر روی یک گوشی هوشمند ارائه می‌دهد:



**گزینه 1: برنامه‌های کاربردی سازگار با موبایل




- دانلود **Zeus** یا **BlueWallet** از اپ استور یا گوگل پلی
- افزونه **LndHub** را در LNbits برای این Wallet فعال کنید.
- کد QR LndHub را با اپلیکیشن موبایل اسکن کنید تا به Wallet متصل شوید.



**گزینه ۲: دسترسی مستقیم از طریق مرورگر موبایل**




- کد QR نمایش داده شده در "Export to Phone with QR Code" حاوی URL کامل Wallet با احراز هویت یکپارچه است.
- این کد QR را با گوشی هوشمند خود اسکن کنید تا Wallet را مستقیماً در مرورگر موبایل خود باز کنید.
- افزودن صفحه به صفحه اصلی برای دسترسی سریع



**امنیت مهم**: این URL حاوی کلیدهای API برای دسترسی کامل به Wallet است. هرگز آن را به صورت عمومی به اشتراک نگذارید. با این کد QR همانند کلیدهای خصوصی Bitcoin خود رفتار کنید - هر کسی که این کد QR را اسکن کند به طور کامل به Wallet دسترسی پیدا می‌کند.



این ویژگی موبایل، نمونه LNbits Umbrel شما را به یک سرور واقعی Lightning Wallet برای شما و دوستانتان تبدیل می‌کند، در حالی که به لطف نود خودمیزبان، حاکمیت کامل بر وجوه خود را حفظ می‌کنید.



### اشتراک‌گذاری دسترسی کاربر



مورد اصلی برای این پیکربندی چندکاربره **اشتراک‌گذاری کیف‌پول‌ها با خانواده یا دایره نزدیکان شما** است. هنگامی که یک کاربر با Wallet اختصاصی (مانند "Satoshi" در مثال ما) ایجاد کردید، می‌توانید این اطلاعات ورود را با اعضای مورد اعتماد خانواده خود به اشتراک بگذارید.



**دسترسی به امنیت در Umbrel**: دسترسی به نمونه LNbits شما در Umbrel به طور طبیعی محافظت شده است، زیرا فقط می‌توان به آن دسترسی داشت :




- در شبکه محلی شما** : اعضای خانواده شما که به همان شبکه WiFi/Ethernet متصل هستند می‌توانند به این نمونه دسترسی داشته باشند
- از طریق VPN**: اگر از VPN مانند Tailscale که بر روی سرور Umbrel شما تنظیم شده است استفاده کنید، کاربران مجاز می‌توانند به صورت امن از راه دور دسترسی پیدا کنند.



این محافظت دوگانه Layer (دسترسی شبکه + احراز هویت کاربر) گزینه "اجازه ایجاد کاربران جدید" را در Umbrel کمتر بحرانی می‌کند. تنها افرادی که از قبل به شبکه یا VPN شما دسترسی دارند می‌توانند به ورود Interface دسترسی پیدا کنند.



**سناریوی معمول**: شما یک حساب "پدر"، یک حساب "مادر"، یک حساب "کسب‌وکار" و غیره ایجاد می‌کنید. هر عضو خانواده دارای Wallet Lightning جداگانه خود است، در حالی که از نقدینگی مشترک نود Umbrel شما بهره‌مند می‌شود. به سادگی نام کاربری و رمز عبور را به اشتراک بگذارید - سپس کاربر می‌تواند از هر دستگاهی در شبکه محلی شما یا از طریق VPN Tailscale شما متصل شود. لطفاً برای اطلاعات بیشتر به آموزش اختصاصی Tailscale ما مراجعه کنید:



https://planb.academy/tutorials/computer-security/communication/tailscale-9acbd7de-04d9-40f6-ab80-35f0dfedb632

### افزونه‌های موجود را بررسی کنید



به Interface SuperUser بازگردید و به منوی "Extensions" در پانل سمت چپ دسترسی پیدا کنید تا اکوسیستم کامل افزونه‌های LNbits را کشف کنید.



![Extensions disponibles](assets/fr/16.webp)



LNbits مجموعه‌ای غنی از افزونه‌ها ارائه می‌دهد که نمونه شما را به یک پلتفرم واقعی خدمات Lightning تبدیل می‌کند:





- جعبه موسیقی**: سیستم جعبه موسیقی با قدرت Sats (پرداخت‌های Spotify)
- تیکت‌های پشتیبانی**: سیستم پشتیبانی پولی (دریافت ساتس برای پاسخ به سوالات)
- TPoS**: ترمینال فروش نقطه‌ای امن و سیار برای خرده‌فروشان
- مدیر کاربر**: مدیریت کاربر پیشرفته و Wallet (که به تازگی استفاده کرده‌ایم)
- رویدادها**: فروش و اعتبارسنجی بلیط‌های رویداد
- LNURLDevices**: مدیریت نقطه فروش، دستگاه‌های خودپرداز، سوئیچ‌های متصل
- SMTP**: به کاربران اجازه دهید ایمیل ارسال کنند و ساتس کسب کنند
- بولت‌کارت‌ها**: برنامه‌ریزی کارت‌های NFC برای پرداخت‌های لایتنینگ با ضربه زدن
- NostrNip5**: ایجاد آدرس‌های NIP5 برای دامنه‌های شما
- پرداخت‌های‌تقسیمی**: توزیع خودکار پرداخت‌ها بین چندین کیف‌پول



هر افزونه با یک کلیک از این Interface فعال می‌شود. افزونه‌هایی که با "FREE" علامت‌گذاری شده‌اند، رایگان هستند، در حالی که برخی به عنوان نسخه‌های "PAID" در دسترس هستند. کاتالوگ را مرور کنید تا آن‌هایی که با نیازهای شما مطابقت دارند را شناسایی کنید - چه برای کسب‌وکار، مدیریت خانواده، یا آزمایش قابلیت‌های Lightning Network.



## مزایا و محدودیت‌ها



**مزایا**: حاکمیت مالی (کنترل کامل بر وجوه/کلیدها/داده‌ها)، انعطاف‌پذیری معماری (مهاجرت بدون از دست دادن VPS→Full node)، سیستم توسعه حرفه‌ای، Interface شهودی.



**محدودیت‌ها** : نرم‌افزار در نسخه بتا (احتیاط در مورد مقادیر)، امنیت تحت مسئولیت مدیر، URLهایی که حاوی کلیدهای حساس API هستند (HTTPS اجباری است)، مدیریت چندکاربره به معنای مسئولیت نگهداری است.



## بهترین روش‌ها



**پشتیبان‌گیری‌ها**: seed PHOENIXD/credentials LND، پایگاه داده LNbits، فایل‌های `.env`. به صورت روزانه خودکارسازی شود، از سرور تولید جدا نگه‌داری شود، رمزگذاری شده. بازیابی‌ها را به طور منظم آزمایش کنید.



**نگهداری**: به‌طور منظم به‌روزرسانی‌ها را بررسی کنید (LNbits، بک‌اند Lightning، سیستم‌عامل). همیشه قبل از به‌روزرسانی‌های عمده، یادداشت‌های انتشار را بررسی کنید.





- روی Umbrel**: فروشگاه برنامه به‌طور خودکار شما را از نسخه‌های جدید مطلع می‌کند. افزونه‌ها را از طریق "مدیریت افزونه‌ها" > "به‌روزرسانی همه" همگام‌سازی کنید. بررسی کنید که آیا پایگاه داده SQLite در پشتیبان‌گیری‌های خودکار Umbrel گنجانده شده است.
- روی VPS**: به‌صورت دستی به‌روزرسانی کنید با `cd lnbits && git pull && uv sync --all-extras && sudo systemctl restart lnbits`. لاگ‌های سیستم را نظارت کنید: `sudo journalctl -u lnbits -f`.



## نتیجه‌گیری



میزبانی شخصی LNbits راهی ملموس به سوی حاکمیت مالی لایتنینگ ارائه می‌دهد. VPS+PHOENIXD یک راه‌حل سبک برای خدمات سریع ارائه می‌دهد، یکپارچگی کامل Umbrel با نود موجود Bitcoin. معماری مقیاس‌پذیر امکان تکامل از Wallet چندکاربره ساده به موارد استفاده تجاری پیچیده را فراهم می‌کند.



میزبانی شخصی به معنای مسئولیت است: پشتیبان‌گیری از کلیدها، محافظت از دسترسی، شروع با مقادیر کم. با این احتیاطات، LNbits به یک راه‌حل قوی برای اقتصاد لایتنینگ تبدیل می‌شود، در حالی که تمرکززدایی و خودمختاری را حفظ می‌کند.
