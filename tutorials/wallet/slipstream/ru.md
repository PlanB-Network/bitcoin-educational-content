![cover](assets/cover.webp)

Обычно, когда вы подписываете транзакцию, она автоматически транслируется на каждую ноду сети Bitcoin. Затем она ожидает попадания в блок.

Однако, пока транзакция не включена в блок, злоумышленник, получивший ваш приватный ключ, может заменить ее и украсть средства. Обычно это касается случаев, когда вы используете аппаратный кошелек ColdCard.

Инструмент Slipstream от майнинговой компании MARA позволяет обойти трансляцию транзакции в сеть: она отправляется напрямую (и только) майнеру, что сохраняет ее в тайне и не позволяет ей "засветиться" в сети. Транзакция, вероятно, будет подтверждаться дольше, но она будет защищена от атаки с заменой.

Ниже мы предлагаем туториал, позволяющий пользователям [Liana](https://planb.academy/tutorials/wallet/desktop/liana-306ef457-700c-4fdd-b07a-8fb7a8a29f04), а также пользователям кошелька [Sparrow](https://planb.academy/tutorials/wallet/desktop/sparrow-c674e2ac-d46f-4c82-92a7-7d1b0e262f5d), использовать инструмент Slipstream майнера MARA через страницу [outofband.wizardsardine.com](https://outofband.wizardsardine.com/).

⚠️ **Внимание**: этот инструмент предназначен только для определенных профилей, в основном для кошельков Liana, miniscript-кошельков и некоторых типов мультисига. Wizardsardine **явно не рекомендует** использовать его для кошельков, средства которых уже находятся под критическим риском кражи, например тех, чья сид-фраза была сгенерирована на устройстве ColdCard, затронутом уязвимостью генератора случайных чисел. В такой ситуации гонка со злоумышленником идет на секунды, а транзакция, отправленная одному-единственному майнеру, подтверждается гораздо дольше, чем обычная транслируемая транзакция. Если это вас касается, сначала прочитайте наш отдельный туториал:

https://planb.academy/tutorials/wallet/hardware/coldcard-seed-vulnerability-1348b153-89db-429c-80af-b5d3d8506b9a

## Для пользователей Liana

Liana поддерживается компанией Wizardsardine, издателем страницы [outofband.wizardsardine.com](https://outofband.wizardsardine.com/), поэтому путь здесь прямой: вы просто экспортируете файл подписанного PSBT вместо того, чтобы транслировать его.

*Предварительное условие: наличие средств на вашем кошельке Liana.*

### Шаг 1: Создайте транзакцию в Liana

Как обычно, создайте транзакцию, указав адрес назначения, описание и сумму (в данном случае — максимально доступную сумму в кошельке).

Чтобы задать размер комиссии:

- выберите монеты, которые хотите потратить, нажав на небольшой квадрат внизу слева, под надписью "Coins selection";
- затем введите размер комиссии. Не забудьте установить комиссию значительно выше предложенной ставки, как описано на этой странице: [outofband.wizardsardine.com](https://outofband.wizardsardine.com/).

Наконец, нажмите "Next".

![Building the transaction in Liana](assets/fr/01.webp)

### Шаг 2: Проверьте детали транзакции

Прежде чем нажать "Sign", проверьте детали транзакции; в частности:

- отправляемую сумму;
- количество сатоши, выделенных на комиссию за транзакцию;
- но прежде всего адрес, на который вы отправляете средства (не забудьте проверить первые 5/6 символов, последние 5/6 и 5/6 символов в середине адреса, чтобы избежать атак типа "отравление адреса" (address poisoning)).

![Checking the transaction details](assets/fr/02.webp)

### Шаг 3: Выберите кошельки для подписания

Далее выберите программные и/или аппаратные кошельки, которыми вам нужно подписать транзакцию. Небольшое напоминание: в случае мультисиг-кошелька 2-из-2 вам понадобятся 2 подписи из 2.

### Шаг 4: Экспортируйте файл PSBT вашей транзакции

Теперь транзакция Bitcoin подписана нужными ключами. Не нажимайте "Broadcast", иначе она будет распространена по всей сети, и, если вы используете аппаратный кошелек ColdCard, ваша транзакция окажется публично раскрыта, а ваши средства подвергнутся риску.

Теперь вы можете нажать "Export", а затем сохранить файл PSBT локально на своем компьютере.

![Exporting the PSBT file from Liana](assets/fr/03.webp)

### Шаг 5: Отправьте транзакцию майнеру через outofband.wizardsardine.com

Теперь перейдем к финальным шагам. Чтобы отправить транзакцию майнеру, всё, что вам нужно сделать, — это взять файл PSBT и перетащить его в отведенную область.

![Dropping the PSBT file on outofband.wizardsardine.com](assets/fr/04.webp)

Транзакция отобразится, как показано ниже.

![Transaction in the queue](assets/fr/05.webp)

### Шаг 6: Отправьте транзакцию через Slipstream

Наконец, всё, что вам нужно сделать, — это нажать "Send", чтобы транзакция была отправлена в MARA через Slipstream.

![Sending the transaction via Slipstream](assets/fr/06.webp)

Через несколько секунд транзакция перейдет из статуса "Sending" в статус "Accepted":

![Transaction accepted by Slipstream](assets/fr/07.webp)

Остается лишь скопировать идентификатор транзакции (TXID), а затем вставить его на [mempool.space](https://mempool.space/), чтобы наблюдать за ее подтверждением:

![Looking up the TXID on mempool.space](assets/fr/08.webp)

Обратите внимание: транзакция будет отображаться как "Transaction not found", пока майнер MARA не намайнит блок и не включит в него вашу транзакцию. Это может занять от нескольких десятков минут до нескольких часов, поскольку MARA владеет лишь около 4,5% хешрейта сети Bitcoin. По состоянию на 4 августа 2026 года это соответствует примерно одному намайненному блоку каждые 3 часа 45 минут.

## Для пользователей других кошельков

Для этого мы будем использовать программный кошелек [Sparrow](https://planb.academy/tutorials/wallet/desktop/sparrow-c674e2ac-d46f-4c82-92a7-7d1b0e262f5d).

*Предварительное условие: наличие средств на вашем кошельке Sparrow.*

### Шаг 1: Создайте транзакцию

С помощью [Sparrow](https://planb.academy/tutorials/wallet/desktop/sparrow-c674e2ac-d46f-4c82-92a7-7d1b0e262f5d) создайте транзакцию на своем мультисиг-кошельке. Не забудьте установить комиссию значительно выше предложенной ставки, как описано на этой странице: [outofband.wizardsardine.com](https://outofband.wizardsardine.com/).

После создания нажмите "Create Transaction".

![Creating the transaction in Sparrow](assets/fr/09.webp)

### Шаг 2: Финализируйте транзакцию

Чтобы финализировать транзакцию, теперь нужно ее подписать. Для этого нажмите "Finalize Transaction for Signing".

![Finalizing the transaction for signing](assets/fr/10.webp)

### Шаг 3: Подпишите транзакцию разными ключами

Теперь настало время подписать транзакцию. Для этого просто подпишите ее с помощью используемых вами программных или аппаратных кошельков.

![Signing the transaction with the multisig keys](assets/fr/11.webp)

### Шаг 4: Скачайте подписанную транзакцию и не транслируйте ее в сеть

Теперь транзакция Bitcoin подписана обоими ключами нашего мультисига 2-из-2. Не нажимайте "Broadcast Transaction", иначе она будет распространена по всей сети, и, если вы используете аппаратный кошелек ColdCard, ваша транзакция окажется публично раскрыта, а ваши средства подвергнутся риску.
