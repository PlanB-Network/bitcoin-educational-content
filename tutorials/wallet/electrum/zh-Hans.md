## 为什么选择 Electrum？

这是一份关于如何使用 Electrum 比特币钱包的详细指南，其中包含了所有陷阱和缺陷的解决方案——这是我在多年使用以及教授学生比特币安全/隐私知识后总结出来的。Electrum 并非那些希望一切尽可能简单、只想停留在入门阶段的用户的最佳选择。相反，它更适合那些已经是或渴望成为“高级”用户的人。

对于比特币新手来说，只有在经验丰富的用户指导下使用 Electrum 钱包才是最佳选择。如果独自学习，只要他们循序渐进，并在测试环境中先使用少量聪（sats）进行练习，使用起来也是安全的。本指南旨在支持这种学习方式，同时也是其他用户的良好参考资料。

> 警告：本指南篇幅较长，因此请勿尝试在一天内完成所有步骤。建议您将本指南放在手边，并随着时间的推移稳步学习。

## 验证 Electrum 真实性

“验证”下载的目的是确保没有一个数据位被篡改。它防止您使用 “黑客攻击” 的恶意软件版本。只要您仅用下载的副本进行练习，即不使用持有重要金额的钱包，就可以跳过这一步。然后，一旦您准备好使用 Electrum 来管理您的真实资金，您应该删除您的副本并重新开始，这次验证您的下载。
为此，我们使用公钥/私钥加密工具 - gpg，我们在这里（https://armantheparman.com/gpg/）编写了一个关于它的指南。gpg 工具随所有 Linux 操作系统提供。对于 Mac 和 Windows，请查看 gpg 链接以获取下载说明。
除了下载 Electrum 软件外，出于安全考虑，您还需要该软件的数字签名。这是一串文本（实际上是使用文本编码的数字），由开发者用他的私人 gpg 密钥生成。使用 gpg 程序，我们可以 “测试” 签名与他的公钥（由开发者的私钥创建）相对应，每个人都可以访问公钥，与下载文件相比较。

换句话说，通过三个输入（签名、公钥和数据文件），我们可以得到一个真或假的输出，以确认文件未被篡改。

为了计算这个签名，请点击与您下载的文件对应的链接（见图中的箭头）：

![image](assets/2.webp)

点击链接可能会自动将文件下载到您的下载文件夹，或者可能在浏览器中打开。如果它在浏览器中打开，您需要保存文件。您可以右键点击并选择 “save as”。根据操作系统或浏览器的不同，您可能需要在空白区域右键点击，而不是文本。

以下是下载的文本样子。您可以看到有多个签名 - 这些是不同人的签名。您可以验证每一个或任何一个。我将向您展示如何仅验证开发者的签名。

![image](assets/3.webp)

接下来，您需要获取 ThomasV 的公钥 - 他是主要开发者。您可以直接从他那里、他的 Keybase 账户、Github 或其他人那里、从密钥服务器或从 Electrum 网站获取。

从 Electrum 网站获取实际上是最不安全的方式，因为如果这个网站是恶意的（我们正在检查的正是这个问题），为什么我们要从它那里获取公钥（公钥可能是假的）？

为了现在保持简单，我还是会向您展示如何从网站获取，但请记住这一点。这是 GitHub 上的副本（https://github.com/spesmilo/electrum/blob/master/pubkeys/ThomasV.asc），您可以将其进行比较。

向下滚动页面一点以找到 ThomasV 的公钥链接（下面的红圈）。点击它并下载，或者如果它在浏览器中打开了一些文本，右键点击保存。

![image](assets/4.webp)

您现在有了 3 个新文件，可能都在下载文件夹中。它们在哪里并不重要，但如果您将它们全部放在同一个文件夹中，会使过程更加容易。

三个文件包括：

1. Electrum 下载
2. 签名文件（通常与 Electrum 下载的文件名相同，附加 “.asc”）
3. ThomasV 的公钥。

在 Mac 或 Linux 上打开终端，或在 Windows 上打开命令提示符（CMD）。

前往到 Downloads 目录（或您放置这三个文件的任何位置）。如果您不知道这意味着什么，请从 Linux/Mac 的这个短视频（https://www.youtube.com/watch?v=AO0jzD1hpXc）和 Windows 的这个视频（https://www.youtube.com/watch?v=9zMWXD-xoxc）中学习。记住，在 Linux 计算机上，目录名称区分大小写。
在终端中，输入以下命令将 ThomasV 的公钥导入到您计算机的 “keyring1” 中（keyring 是一个抽象概念——实际上它只是您计算机上的一个文件）：
```bash
gpg --import ThomasV.asc
```

请确保文件名与您下载的文件名匹配。同时注意，这里使用的是双破折号而不是单破折号。还要注意“--import” 前后都有空格。然后按 <enter> 键。

文件应该会被导入。如果出现错误，请检查您是否在该文件实际存在的目录中。要检查您所在的目录（在 Mac 或 Linux 上），输入 pwd。为了查看您所在目录中的文件（在 Mac 或 Linux 上），输入 ls。您应该会看到列出的 “ThomasV.asc” 文本文件，可能还有其他文件。

然后我们运行命令以验证签名。

```bash
gpg --verify Electrum-4.1.5.tar.gz.asc Electrum-4.1.5.tar.gz
```

注意这里有 4 个 “元素”，每个元素之间由一个空格分隔。我交替加粗了文本以帮助您看清楚。这四个元素包括：

1. gpg 程序
2. --verify 选项
3. 签名的文件名
4. 程序的文件名

值得注意的是，有时您可以省略第 4 个元素，计算机会猜测您的意思。我不确定，但我相信这只在文件名仅由末尾的 “asc” 不同的情况下才有效。

不要仅仅复制我这里显示的文件名——确保它们与您系统上的文件名匹配。

按 <enter> 键运行命令。您应该会看到 “good signature from ThomasV” 以表示成功。会有一些错误，因为我们没有签名文件中包含的其他人的公钥（在后续版本中，这种将签名合并在一个文件中的系统可能会改变）。此外，底部还有一个我们可以忽略的警告（这是在提醒我们，我们没有明确告诉计算机我们信任 ThomasV 的公钥）。

现在我们有了一个经过验证的 Electrum 副本，可以安全使用了。

## 运行 Electrum

### 如果使用 Python 运行 Electrum

如果您下载了 Python 版本，这是使其工作的方法。您会在下载页面上看到这个：

![image](assets/5.webp)

对于 Linux，首先，您要更新您的系统：

```bash
sudo apt-get update
sudo apt-get upgrade
```

复制黄色高亮的文本，粘贴到终端中，然后按 <enter> 键。您可能会被要求输入密码，可能还需要确认继续，然后它将安装那些文件（“dependencies”，即依赖项）。

您还需要将压缩文件解压到您选择的目录中。您可以使用图形用户界面来做这件事，或者从命令行中做（粉红色高亮的命令）——记住您的文件名可能会有所不同。（注意，当我们在前一节中验证下载时，我们验证的是 zip 文件，而不是解压后的目录。）

虽然可以选择使用 PIP 程序进行“安装”，但这没有必要，而且会增加额外的步骤和文件安装。只需通过终端运行程序即可绕过所有这些步骤。

步骤（Linux）如下：

1. 前往到提取文件的目录
2. 输入：./run_electrum

在 Mac 上，步骤相同，但您可能需要首先安装 Python3，并使用此命令运行：

```bash
python3 ./run_electrum
```

一旦 Electrum 运行起来，终端窗口将保持打开状态。如果您关闭它，Electrum 程序将会终止。使用Electrum 时，只需最小化它即可。

### 使用 Appimage 运行 Electrum

这个方法稍微简单一些，但不如 Windows 可执行文件那样简单。根据您使用的 Linux 版本，默认情况下，Appimage 文件可能会被系统设置为禁止执行的属性。我们必须更改这一设置。如果您的 Appimage 可以正常工作，您可以跳过这一步。使用终端前往到文件所在位置，然后运行以下命令：

```bash
sudo chmod ug+x Electrum-4.1.5-x86_64.AppImage
```

“sudo” 提供超级用户权限；“chmod” 是一个用于更改模式的命令，改变每个人的权限、写入或执行；“ug+x” 意味着我们正在修改用户和组以允许执行。

根据您的版本调整文件名。

然后，通过双击 Appimage 图标即可运行 Electrum。

### 在 Mac 上运行 Electrum

只需双击下载的文件（它是一个“驱动器”）。一个窗口会出现。将 Electrum 图标从窗口拖到您的桌面上，或者您想要保存程序的任何地方。然后，您可以 “eject（弹出）” 驱动器，并删除驱动器（下载的文件）。

为了运行该程序，只需双击即可。您可能会遇到一些 Mac 特有的 “安全提示” 错误，需要绕过这些错误。

### 在 Windows 上运行 Electrum

尽管我最不喜欢 Windows，但这是最简单的方法。只需双击可执行文件即可运行。

您可以将名称保留为 “default_wallet” 或更改为您喜欢的名称，然后点击下一步。稍后，如果您有多个钱包，您可以在这个阶段通过首先点击“Choose...” 来找到它们并打开。

种子随后生效。（在此之前，Electrum 期望的是一个 Electrum 的种子，因此该种子被视为无效。）在点击 “Next” 之前，请注意 “Checksum OK” 的提示。这一点很重要（对于您之后可能使用的实际钱包而言），因为该提示确认了您输入的种子的有效性。底部附近的警告可以忽略，那是 Electrum 开发者对 BIP39 的抱怨，以及他们声称自己的版本（与其他钱包不兼容）更优越的 “FUD” 言论。

> **此处插入一条重要警告：**校验和的作用是确保您输入的种子没有错误。校验和是种子的最后一部分（第 12 个单词是校验和单词），它由种子的第一部分（11 个单词）的数学值计算得出。如果您在开头输入错误，校验和单词将无法匹配，钱包软件会发出警告提醒您。这并不意味着助记词不能用于创建功能正常的比特币钱包。想象一下，您创建了一个钱包，但输入错误，然后向钱包充值了比特币。之后有一天，您可能需要恢复钱包，但恢复时您不会重现输入错误——您会恢复错误的钱包！Electrum 允许您在校验和无效的情况下继续创建钱包，这非常危险，所以请注意，确保校验和是您的责任。其他钱包会阻止您继续操作，这要安全得多。这就是我所说的，一旦您学会正确使用 Electrum，它就可以安全使用的原因之一（Electrum 的开发者应该修复这个问题）。

请注意，如果您想添加 passphrase（密语），可以在选项窗口的顶部找到选择。

点击 “OK” 后，您会回到输入助记词的位置。如果您选择了密语选项，请不要将其与助记词一起输入（提示信息会在后面出现）。

如果您没有请求密语，接下来您将看到此屏幕——更多关于钱包脚本类型和派生路径的选项，您可以在这里了解（https://armantheparman.com/public-and-private-keys/），但只需保留默认值并继续即可。

有一些事情我建议您做以设置软件环境（只需一次）：

### 将单位更改为 BTC

转到顶部选单，tools –> electrum preferences，在那里的通用标签下，您会找到将 “base unit” 更改为BTC的选项。请启用 Addresses and Coins 标签

前往顶部选单，查看，然后选择 “show addresses”。然后返回查看并选择 “show coins”。

### 启用 Oneserver

默认情况下，Electrum 将连接到一个随机节点。它还连接到许多其他次要节点。我不确定与这些次要节点交换了什么数据，但我们不希望这样做，出于隐私考虑。即使您指定了一个节点，例如您自己的节点，这些多个其他节点也会同时连接，我不确定正在共享什么信息。无论如何，防止这种情况很容易。在我向您展示如何指定您自己的节点之前，我们将强制 Electrum 一次只连接到一个服务器。

> 有一种方法可以通过从命令行指定 “oneserver” 来做到这一点，但我不推荐这种方式。我将展示一个我认为从长远来看更简单的替代方法，而且更不容易让您意外地连接到其他节点。

我们使用虚拟钱包的原因是，如果我们加载了我们的真实钱包，带有我们真实的比特币，我们现在已经无意中连接到了一个随机节点（即使我们在开始时选择了“手动设置服务器”，它仍然会出于某种原因连接到这些其他辅助节点（嘿，Electrum 开发者，您们应该解决这个问题）。如果我们的钱包是私有的，这将是一场灾难。

此外，如果不先加载某种类型的钱包，我们就无法执行我下面要展示的步骤。（我们将编辑一个配置文件，该文件只有在加载钱包后才会生成并可供编辑）。

现在关闭 Electrum **（重要提示：如果您不这样做，您接下来所做的更改将被清除）**。

### LINUX/MAC 配置文件

在 Linux 或 Mac 中打开终端（稍后提供 Windows 指令）：

您应该自动位于 home 文件夹中。从那里，前往到隐藏的 electrum 设置文件夹（这与应用程序所在的位置不同）。

```bash
cd .electrum
```

注意 “electrum” 前的点表示它是一个隐藏文件夹。

另一种方式是输入以下命令：

```bash
cd ~/.electrum
```

其中 “~” 代表您的主目录的路径。您可以使用 “pwd” 命令来查看当前目录的完整路径。

一旦进入 “.electrum” 目录，输入 “nano config” 并按 <enter> 键。

一个文本编辑器将打开（称为 nano）并打开配置文件。这里鼠标不怎么管用。使用箭头键移动到以下行：

```json
"oneserver": false,
```

将 “false” 更改为 “true”；并且不要破坏语法（不要删除逗号或分号）。

按 <ctrl> x 以退出，然后按 “y” 以保存，然后按 <enter> 确认更改而不编辑文件名。
现在再次运行 Electrum。然后点击右下角的圆圈，这将打开网络设置。然后，在概览标签页的顶部附近，您会看到 “connected to 1 node（已连接到 1 个节点）”——这表示成功。

就在下面，您会看到一个文本字段，服务器的地址就在那里。您目前连接到了那个随机节点。关于连接到节点的更多信息，请看下一节。

### Windows 配置文件

Windows 配置文件有点难找。目录为：`C:/Users/Parman/AppData/Roaming/Electrum`

显然，您需要将 “Parman” 更改为您自己的计算机用户名。

在那个文件夹中，您会找到配置文件。用文本编辑器打开它，并编辑以下行：

```json
"oneserver": false,
```

这里需要注意一点：UTXO 仅存在于交易内部。要花费一个 UTXO，我们需要引用它，并将该引用作为新交易的输入。这样，输出就变成了新的 UTXO，而旧的 UTXO 则变成了 STXO（已花费交易输出）。

第二行是 10,000 聪的捐赠。它对应的交易哈希旁边有一个 “0”，因为它是该交易的第一个（也可能是唯一的）输出。

在底部窗口中，我们可以看到我们的地址。请注意，输入的比特币总数与输出的比特币总数并不完全匹配。差额将支付给矿工。矿工会查看它正在挖矿的区块中所有交易的差额，并将该差额添加到它的奖励中。（这种挖矿费用与交易链完全脱钩，并开始新的生命周期。）

如果我们调整挖矿费用，输出值将自动更改。

**这里需要特别注意：** 请注意交易窗口中地址的颜色。请记住，绿色的地址会列在您的地址标签页中。如果某个地址在交易窗口中以绿色（或黄色）高亮显示，则表示 Electrum 已将该地址识别为自己的地址。如果地址没有高亮显示，则表示它是外部地址（当前打开的钱包之外的地址），您应该格外仔细地检查它。

检查完交易中的所有内容，确认您对所花费的币种及其去向都满意后，即可点击“Finalise”。

![image](assets/42.webp)

点击 “finalise” 后，您将无法再进行任何编辑——如果需要修改，您必须关闭此窗口并重新开始。请注意，“finalise” 按钮已更改为 “export”，并且出现了新的按钮：“save”、“combine”、“sign” 和 “broadcast”。“broadcast” 按钮呈灰色，因为交易尚未签名，因此在此阶段无效。

一旦您点击签名，如果您的钱包已设置了密码，系统会提示您输入密码，然后状态（右上角）会从 “Unsigned” 变为 “Signed”。然后 “Broadcast” 按钮将可用。

在您广播交易后，可以关闭交易窗口。如果您转到地址标签页，现在会看到第一个地址为空，而第二个地址有 1 个 UTXO。

注意：即使交易尚未被挖出到区块或 “confirmed”，您也会看到所有这些变化。这是因为 Electrum 不仅基于区块链数据更新余额/交易，还基于内存池数据。并非所有钱包都支持此功能。

### 找零地址

找零地址很有意思。您需要了解 UTXO 才能理解以下说明。如果您要花费到某个地址的金额小于 UTXO，那么剩余的比特币将归矿工所有，除非您指定了找零输出。

假设您有一个 6.15 比特币的 UTXO，您想花费 0.15 比特币捐赠给世界上某个地方被暴政“民主”政府压迫的抗议者。这时，您可以使用 Electrum 的 “spend from” 功能，将这 6.15 比特币放入一个交易中。

您需要将抗议者的地址粘贴到 “Pay to” 字段中，或许可以在 “description” 字段中填写“EndTheFed & WEF”，然后在金额栏中填写 0.15 比特币，点击 “pay”，然后点击 “advanced”。

在交易界面的输入窗口中，您会看到 6.15 比特币的 UTXO。在输出窗口中，您会看到一个未高亮显示的地址（这是抗议者的地址），旁边显示 0.15 个比特币。您还会看到一个黄色地址，显示略少于 6.0 个比特币。这是钱包从其自身的黄色找零地址中自动选择的找零地址。找零地址的作用是让钱包可以存放找零，而不会影响您可能计划使用或已发送发票的收款地址的可用性。例如，如果这些地址稍后将由客户使用，您肯定不希望钱包自动使用并填充它们。这样做既混乱又不利于隐私。

请注意，当您调整挖矿费用时，找零输出金额会自动调整，但支付金额不会。

## 钱包

我想用 Electrum 演示一个只读钱包。为此，我首先需要定义“钱包”。在比特币中，“钱包”有两种用法：

- A 类 “钱包”——指的是显示您的地址和余额的软件，例如 Electrum、Blue Wallet、Sparrow Wallet 等。

- B 类 “钱包”——指的是与我们的助记词/密语/派生路径组合关联的唯一地址集合。任何钱包中都包含 86 亿个地址（43 亿个接收地址和 43 亿个找零地址）。如果您更改助记词、密码或派生路径中的任何内容，您将获得一个全新的、包含 86 亿个唯一地址的全新钱包。

在上下文中，人们使用“钱包”一词时指的是哪种类型显而易见。

那么它的意义何在呢？

其中一个原因（并非主要原因）是，您可以在电脑上查看您的钱包及其余额，而无需将私钥暴露给电脑上的任何恶意软件。

另一个原因是，如果您选择将私钥保存在电脑之外，则必须使用硬件钱包才能进行支付；我来解释一下：

> 硬件钱包 (HWW)** 的设计初衷是让设备能够安全地存储您的私钥（使用 PIN 码锁定），永远不会将密钥暴露给电脑（即使通过数据线连接到电脑），并且设备本身也无法连接到互联网。这样的设备无法自行进行交易，因为所有比特币交易都始于引用区块链（位于节点上）上的 UTXO。钱包必须指定 UTXO 所在的交易 ID，以及要花费的交易输出。只有在指定输入之后，才能创建新的交易，更不用说签名了。硬件钱包无法创建交易，因为它们无法访问任何UTXO——它们没有连接到任何东西！
通常会从硬件钱包（HWW）中提取扩展公钥，然后将地址显示在计算机上——许多人都熟悉 Ledger 软件或Trezor Suite，它们会在计算机上显示地址和余额——这就是监视钱包。这些程序可以创建交易，但它们无法签名。它们只能让连接到它们的硬件钱包对交易进行签名。硬件钱包从监视钱包获取新生成的交易，对其进行签名，然后将其发送回计算机，以便广播到节点。**硬件钱包本身无法广播交易**，广播是由其关联的监视钱包完成的。这样，两个钱包（计算机上的公钥钱包和硬件上的私钥钱包）就能协同工作，生成、签名并广播交易，同时确保私钥始终处于隔离状态，远离联网设备。

## 部分签名的比特币交易（PSBT）

交易可以先被创建并保存到文件中，之后重新加载、签名、保存，再次重新加载，最后广播出去——我并不是说每个人都需要这样做；这只是理论上可行的方法。

现在考虑一个 3/5 多签名钱包——钱包由 5 个私钥组成，需要其中 3 个私钥才能完成交易签名（点击此处了解更多关于多重签名钱包密钥的信息）。假设有 5 台不同的计算机，每台计算机都拥有这 5 个私钥中的一个。

计算机 1 可以生成并签名一笔交易。然后，它可以将交易保存到文件中，并通过电子邮件发送给计算机 2。计算机 2 可以签名，并可能将文件保存为二维码，然后通过 Zoom 会议将二维码发送给位于世界另一端的计算机 3。计算机 3 可以捕获二维码，将交易加载到 Electrum 中，并签名这笔交易。经过前两次签名后，该交易为 PSBT（部分签名的比特币交易）。经过第三次签名后，该交易即完成签名并生效，可以广播。

为了了解更多关于 PSBT 的信息，请参阅此指南。(https://armantheparman.com/psbt/)

如果以物理隔离的方式使用设备，则需要手动使用 microSD 卡在设备间传输已保存的交易记录。这里有一些技巧。

创建并完成交易后，您需要点击左下角的导出按钮。您会看到 “save to file” 选项，但请注意，这并非我们想要的操作。实际上，您需要先进入最后一个选单选项 “for hardware wallets”，然后在该选项中找到另一个 “save to file” 并选中它。之后，将文件保存到 microSD 卡，取出卡片并将其插入 ColdCard。请记住，您可能需要设置密码短语才能选择正确的钱包。屏幕将显示 “ready to sign”。点击勾选标记，检查交易，然后点击勾选标记确认。完成后，取出卡片并将其放回电脑。

接下来，我们需要使用 Electrum 打开交易记录。该功能隐藏在 “tools” -> “load transaction” 选单中。浏览文件系统并找到该文件。每次签名后都会生成三个文件：仅观察钱包创建的原始保存文件，以及 ColdCard 创建的两个文件（我不知道它为什么会这样做）。其中一个文件会显示 “signed”，另一个会显示 “final”。虽然不太直观，但 “signed” 文件没有用，我们需要打开 “final” 交易记录。

加载完成后，您可以点击 “broadcast”，即可完成支付。

## 更新 Electrum 和隐藏的 “.electrum” 目录

Electrum 在您的计算机上有两个位置。一个是应用程序本身，另一个是一个隐藏的配置文件夹。该文件夹的位置因操作系统而异：

Windows:

```bash
 C:/Users/your_user_name_goes_here/AppData/Roaming/Electrum
```

Mac:

```bash
/Users/your_user_name_goes_here/.electrum
```

Linux:

```bash
/home/your_user_name_goes_here/.electrum
```

请注意，在 Linux 和 Mac 系统中，“electrum”前面的 “.” 表示该目录是隐藏的。此外，请注意，此目录仅在您首次运行 Electrum 时（自动）创建。该目录包含 Electrum 配置文件以及您保存的所有钱包。

如果您从电脑中删除 Electrum 程序，除非您主动删除，否则隐藏目录仍会保留。

为了升级 Electrum，请按照我开头描述的步骤进行下载和验证。之后，您的电脑上将有两个程序副本，您可以运行其中任何一个——每个程序都会访问同一个隐藏的 Electrum 文件夹来进行配置和钱包访问。我们保存的所有内容，例如基本单元、要连接的默认节点、其他首选项以及钱包访问权限，都将保留，因为所有这些信息都保存在该文件夹中。

### 将您的 Electrum 和钱包移动到另一台计算机

为了完成此操作，您可以将程序文件复制到 U 盘，并复制 .electrum 目录。然后将它们复制或移动到新电脑。您无需再次验证程序。请务必将 .electrum 目录复制到默认位置（请记住在首次在该电脑上运行 Electrum 之前复制它，否则默认的 .electrum 文件夹将为空，您可能会感到困惑）。
