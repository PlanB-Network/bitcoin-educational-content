انتقال وجوه بین Bitcoin On-Chain و Lightning Network عموماً نیاز به باز کردن دستی کانال‌های Lightning (فنی و پرهزینه) دارد، یا استفاده از پلتفرم‌های مبادله متمرکز با KYC. SwapMarket یک جایگزین ارائه می‌دهد: مبادلات اتمی Trustless از طریق ارائه‌دهندگان رقابتی، بدون KYC.



نوآوری: اگرچه ارائه‌دهندگان واسطه هستند، HTLC (*قراردادهای زمان‌قفل Hash*) به‌صورت ریاضی تضمین می‌کند که وجوه شما تحت کنترل شما باقی می‌ماند. تجمیع چندین ارائه‌دهنده (Boltz، ZEUS Swaps، Eldamar، Middle Way) رقابت قیمتی ایجاد می‌کند. Interface وب منبع‌باز قابل‌میزبانی‌خود.



## SwapMarket چیست؟



یک گردآورنده متن‌باز که در سال 2024 راه‌اندازی شد، SwapMarket به عنوان مقایسه‌گر ارائه‌دهندگان مبادله Bitcoin/Lightning عمل می‌کند. کاربر به‌صورت فوری شرایط (هزینه‌ها، نقدینگی، محدودیت‌ها) را مقایسه کرده و ارائه‌دهنده بهینه را انتخاب می‌کند.



### معماری فنی



**سمت کاربری فرانت‌اند**: برنامه ۱۰۰٪ سمت کاربری (برنامه وب Fork Boltz) که بر روی GitHub Pages میزبانی می‌شود. کد بدون سرور بک‌اند در مرورگر اجرا می‌شود. تاریخچه به صورت محلی (کوکی‌ها/کش) ذخیره می‌شود. کد منبع عمومی و قابل حسابرسی.



**کشف ارائه‌دهنده** : فهرست کدگذاری‌شده Hard در `src/configs/Mainnet.ts`. ارائه‌دهندگان جدید از طریق Pull Request یا ایمیل اضافه می‌شوند.



**پشتیبان‌های مستقل**: هر ارائه‌دهنده پشتیبان Boltz خود را اجرا می‌کند. Interface به صورت لحظه‌ای APIها را برای مقایسه فوری قیمت‌ها بررسی می‌کند.



**HTLC مبادلات اتمی**: قراردادهای قفل زمانی Hash تضمین می‌کنند که مبادله به صورت اتمی انجام شود: یا مبادله اجرا می‌شود، یا هر طرف وجوه خود را بازیابی می‌کند. ریسک طرف مقابل به صورت ریاضی حذف شده است.



### فلسفه



SwapMarket با ایجاد رقابت بین ارائه‌دهندگان برای کارمزدها و نقدینگی، تمرکززدایی را کاهش می‌دهد. بدون KYC، کد منبع‌باز قابل میزبانی خود، تکثیر اپراتورهای مستقل برای جلوگیری از نقاط شکست واحد.



## ویژگی‌های اصلی



### بازار ارائه‌دهنده



Interface تمام ارائه‌دهندگان فعال را نمایش می‌دهد: نام ارائه‌دهنده، کارمزدهای اعمال‌شده (درصدی و/یا ثابت)، مقادیر حداقل/حداکثر موجود و انواع مبادلات پشتیبانی‌شده. برنامه به‌طور مستقیم APIهای هر ارائه‌دهنده‌ای که در فایل پیکربندی اشاره شده را برای دریافت قیمت‌ها به‌صورت لحظه‌ای پرس‌وجو می‌کند. رقابت بین ارائه‌دهندگان نرخ‌های بهینه را تضمین می‌کند که معمولاً حدود 0.5% برای مبادلات استاندارد است.



### مبادلات دوطرفه



**تعویض (On-Chain → Lightning)**: تبدیل BTCهای On-Chain به ساتوشی‌های Lightning. مورد استفاده: تأمین انرژی یک Wallet Lightning موبایل، به‌دست آوردن ظرفیت ورودی روی یک نود، یا داشتن نقدینگی فوری.



**تعویض (Lightning → On-Chain)**: تبدیل ساتوشی‌های Lightning به BTC در On-Chain. مورد استفاده: تخلیه Lightning در Wallet به ذخیره‌سازی Cold یا متعادل‌سازی نقدینگی بین لایه‌ها.



### ایمنی و بازیابی



**Trustless مبادلات اتمی: HTLC تضمین می‌کند که یا Exchange به‌طور کامل انجام می‌شود، یا هر طرف سهم خود را بازیابی می‌کند. ریسک طرف مقابل به‌طور ریاضی حذف می‌شود.



**مکانیزم بازخرید**: هر مبادله یک تاریخ انقضا دارد (TIMELOCK). اگر مبادله شکست بخورد، وجوه به‌طور خودکار پس از انقضا قابل بازپرداخت هستند. کاربر همیشه گزینه بازپس‌گیری بیت‌کوین‌های خود را دارد.



**کلیدهای بازیابی**: SwapMarket به شما اجازه می‌دهد کلیدهای بازیابی برای مبادلات در حال انجام را صادر کنید. در صورت بروز مشکل، می‌توان از این کلیدها برای نهایی کردن یا لغو یک مبادله از هر دستگاهی استفاده کرد.



## نصب و دسترسی



### Interface وب



SwapMarket نیازی به نصب ندارد. دسترسی از طریق مرورگر با مراجعه به https://swapmarket.github.io امکان‌پذیر است. برای حداکثر محرمانگی، از مرورگرهای Brave، Firefox با افزونه‌های ضد ردیابی، یا LibreWolf استفاده کنید. برای ناشناس بودن در شبکه، مرورگر Tor توصیه می‌شود.



بدون نیاز به ثبت‌نام، ایمیل یا تأیید هویت.



### میزبانی شخصی (اختیاری)



برای کاربران فنی که مایل به حذف هرگونه وابستگی به دامنه رسمی GitHub Pages هستند، SwapMarket می‌تواند به صورت محلی اجرا شود:



**از طریق npm** :


```
git clone https://github.com/SwapMarket/swapmarket.github.io.git
cd swapmarket.github.io
npm install
npm run dev
```



**از طریق داکر** :


```
docker run -p 3000:80 ghcr.io/swapmarket/swapmarket:latest
```



برنامه در `http://localhost:3000` قابل دسترسی خواهد بود. میزبانی شخصی کنترل کامل بر Interface را تضمین می‌کند، خطر سانسور دامنه رسمی را از بین می‌برد و اجازه می‌دهد کد منبع قبل از اجرا بررسی شود.



### پیکربندی اولیه



**Wallet Lightning**: مطمئن شوید که یک Wallet Lightning عملیاتی دارید (Phoenix، Zeus، BlueWallet، و غیره). برای swap-ins، شما یک generate به یک Lightning Invoice خواهید داد. برای swap-outs، شما یک Lightning Invoice پرداخت خواهید کرد.



**Wallet On-Chain**: برای تعویض ورودی، به یک Wallet Bitcoin On-Chain برای ارسال وجوه نیاز دارید. برای تعویض خروجی، یک Bitcoin دریافت کننده Address آماده کنید.



**پیکربندی اختیاری**: SwapMarket تاریخچه و ترجیحات مبادله را در کوکی‌های مرورگر ذخیره می‌کند. نیازی به ایجاد حساب کاربری نیست.

## ایجاد یک مبادله گام به گام



### تعویض: Lightning → Bitcoin



این مثال اول نشان می‌دهد که چگونه ساتوشی‌های لایتنینگ را به بیت‌کوین‌های On-Chain تبدیل کنیم.



**مرحله 1: پیکربندی تعویض**



از صفحه اصلی، فرم مبادله را انتخاب کنید:




- لایتنینگ** (فیلد بالا): مقدار مورد نظر برای ارسال در لایتنینگ Sats را وارد کنید (مثال: 30,000 Sats)
- Bitcoin** (قسم پایین): مبلغی که دریافت خواهید کرد به‌طور خودکار پس از کسر هزینه‌ها نمایش داده می‌شود (مثال: Sats 29,320)



در قسمت پایین، **Bitcoin Address دریافت‌کننده** خود را که می‌خواهید وجوه را دریافت کنید، جای‌گذاری کنید. این Address را با دقت بررسی کنید.



ارائه‌دهنده پیش‌فرض معمولاً Boltz Exchange است. هزینه‌های شبکه و هزینه‌های ارائه‌دهنده به‌وضوح نمایش داده می‌شوند.



![Configuration swap-out](assets/fr/03.webp)



**مرحله 2: انتخاب ارائه‌دهنده**



روی منوی کشویی ارائه‌دهنده کلیک کنید (پیش‌فرض: "Boltz Exchange") تا تمامی ارائه‌دهندگان نقدینگی موجود نمایش داده شوند.



یک پنجره مدال باز می‌شود و یک جدول مقایسه را نمایش می‌دهد:




- وضعیت**: نشانگر Green اگر ارائه‌دهنده فعال باشد
- نام مستعار**: نام ارائه‌دهنده (Boltz Exchange، Middle Way، Eldamar، ZEUS Swaps)
- هزینه**: هزینه‌هایی که توسط ارائه‌دهنده اعمال می‌شود (معمولاً بین 0.49% و 0.5%)
- حداکثر مبادله**: حداکثر مبلغ قابل قبول برای مبادله



هزینه‌ها و حداکثر مبالغ را مقایسه کنید، سپس ارائه‌دهنده مورد نظر خود را انتخاب کنید.



**لطفاً توجه داشته باشید**: در انتخاب ارائه‌دهنده Interface، **مقادیر حداقل** برای هر ارائه‌دهنده نمایش داده نمی‌شود. این اطلاعات تنها پس از انتخاب یک ارائه‌دهنده در ایجاد مبادله Interface ظاهر می‌شود. مقادیر حداقل و حداکثر ممکن است از ارائه‌دهنده‌ای به ارائه‌دهنده دیگر متفاوت باشد و ممکن است با گذشت زمان تغییر کند. **همیشه در زمان مبادله خود این محدودیت‌ها را بررسی کنید**: اگر مبلغی که می‌خواهید مبادله کنید خارج از محدودیت‌های یک ارائه‌دهنده است، می‌توانید ارائه‌دهنده دیگری را که برای تراکنش شما مناسب‌تر است انتخاب کنید.



![Sélection du provider](assets/fr/04.webp)



**مرحله 3: ایجاد Swap و پرداخت Lightning**



روی دکمه زرد **"CREATE ATOMIC SWAP "** کلیک کنید. SwapMarket یک **Lightning Invoice** (BOLT11) برای شما generate می‌کند تا از Wallet Lightning خود پرداخت کنید.



صفحه نمایش می‌دهد :




- شناسه مبادله**: شناسه یکتای مبادله (مثال: J4ymFIMVR6Hm)
- وضعیت**: "swap.created" (مبادله ایجاد شد، در انتظار پرداخت)
- کد QR**: آن را با Wallet Lightning خود اسکن کنید
- Invoice Lightning**: رشته کاراکتری که با "lnbc" شروع می‌شود (مثال: lnbc300u1p50whiv...gn5dk2szgqkvfkzc)



این Invoice را از Wallet Lightning خود پرداخت کنید (Phoenix، Zeus، BlueWallet، و غیره). مبلغ دقیق برای پرداخت نمایش داده می‌شود (مثال: 30,000 Sats).



![Paiement Lightning](assets/fr/05.webp)



**مرحله ۴: تأیید و پذیرش**



به محض تأیید پرداخت لایتنینگ، SwapMarket بلافاصله پرداخت شما را دریافت می‌کند و ارائه‌دهنده تراکنش Bitcoin را به Address شما پخش می‌کند.



وضعیت به **"Invoice.settled "** (Invoice پرداخت شده) تغییر می‌کند و یک پیام تأیید ظاهر می‌شود.



بیت‌کوین‌های On-Chain شما به محض تأیید تراکنش در دسترس خواهند بود (معمولاً در عرض چند دقیقه تا چند ساعت، بسته به کارمزدهای Mining انتخاب شده توسط ارائه‌دهنده).



![Confirmation swap-out](assets/fr/06.webp)



می‌توانید روی **"OPEN CLAIM TRANSACTION "** کلیک کنید تا تراکنش Bitcoin را در یک کاوشگر Blockchain مشاهده کنید.



### تعویض: Bitcoin → Lightning



این مثال دوم نشان می‌دهد که چگونه بیت‌کوین‌های On-Chain را به ساتوشی‌های لایتنینگ تبدیل کنیم.



**مرحله 1: پیکربندی تعویض**



از صفحه اصلی، فرم مبادله را انتخاب کنید:




- Bitcoin** (قسمت بالا): مبلغی را که می‌خواهید در Sats ارسال کنید وارد کنید Bitcoin (مثال: 63,400 Sats)
- LIGHTNING** (قسم پایین): مبلغی که دریافت خواهید کرد پس از کسر هزینه‌ها به‌طور خودکار نمایش داده می‌شود (مثال: 62 884 Sats)



در قسمت پایین، یک Lightning** Invoice (BOLT11) تولید شده از Wallet Lightning خود را جای‌گذاری کنید، یا از LNURL Address خود استفاده کنید اگر Wallet شما از آن پشتیبانی می‌کند.



![Configuration swap-in](assets/fr/07.webp)



**مرحله ۲: بررسی کلید نجات**



پس از کلیک بر روی **"CREATE ATOMIC SWAP "**، یک پنجره مودال ظاهر می‌شود که از شما می‌خواهد کلید نجات خود را تأیید کنید.



![Modal Rescue Key](assets/fr/08.webp)



**کلید نجات بولتز**: همانطور که قبلاً کلید بازیابی خود را در طول پیکربندی اولیه آپلود کرده‌اید (به بخش قبلی مراجعه کنید)، روی دکمه **"VERIFY EXISTING KEY "** کلیک کنید تا کلیدی که ذخیره کرده‌اید وارد شود.



فایل کلید نجات دانلود شده قبلی را انتخاب کنید. پس از تأیید موفقیت‌آمیز، Interface به‌طور خودکار به مرحله بعدی می‌رود.



**مرحله 3: Bitcoin** سپرده Address



SwapMarket اکنون یک **Bitcoin Address منحصر به فرد** تولید می‌کند که حاوی HTLC Contract مرتبط با Lightning Invoice شما است.



صفحه نمایش می دهد :




- شناسه مبادله**: شناسه یکتا (مثال: 1kGmB6JyGqU4)
- وضعیت** : "Invoice.set" (مجموعه Invoice، در انتظار پرداخت Bitcoin)
- کد QR**: Bitcoin انبار Address
- Bitcoin** Address: معمولاً با "bc1p..." شروع می‌شود (مثال: bc1p5mvtwxapjkds...9d4n9f)
- هشدار به رنگ زرد** : "اطمینان حاصل کنید که تراکنش شما در حدود ۲۴ ساعت پس از ایجاد این مبادله تأیید شود!"



این دوره ~24 ساعته **مهلت** HTLC Contract است. اگر تراکنش Bitcoin شما در این بازه زمانی تأیید نشود، مبادله شکست خواهد خورد و شما باید از کلید نجات خود برای بازیابی وجوه خود استفاده کنید.



![Adresse de dépôt Bitcoin](assets/fr/09.webp)



می‌توانید با کلیک بر روی دکمه **"Address"**، Address را کپی کنید، یا کد QR را مستقیماً از Wallet On-Chain خود اسکن کنید.



**مرحله ۴: ارسال بیت‌کوین‌ها**



از Wallet Bitcoin On-Chain خود، **دقیقاً** مقدار مشخص شده (مثلاً 63,400 Sats) را به Address تولید شده ارسال کنید.



**مهم**: از کارمزدهای مناسب Mining استفاده کنید تا تأیید سریع تضمین شود. اگر کارمزد خیلی کم باشد و تراکنش در Mempool فراتر از زمان‌سنج (~24 ساعت) باقی بماند، مبادله شکست خواهد خورد.



پس از ارسال تراکنش، SwapMarket تشخیص می‌دهد که در Mempool است و نمایش می‌دهد:




- وضعیت** : "transaction.Mempool"
- پیام**: "تراکنش در Mempool است - در انتظار تأیید برای تکمیل مبادله"



![Transaction en mempool](assets/fr/10.webp)



**مرحله ۵: تأیید و پذیرش Lightning**



به محض اینکه تراکنش Bitcoin اولین تأیید خود را دریافت کند، ارائه‌دهنده به‌طور خودکار Lightning Invoice شما را پرداخت می‌کند. شما بلافاصله ساتوشی‌ها را بر روی Wallet Lightning خود دریافت می‌کنید.



وضعیت به **"transaction.claim.pending "** تغییر می‌کند، سپس یک پیام تأیید نمایش داده می‌شود:



![Confirmation swap-in](assets/fr/11.webp)



ساتوشی‌های لایتنینگ شما بلافاصله در Wallet شما در دسترس هستند.



## مزایا و محدودیت‌ها



### مزایا



**رقابت نرخ**: تجمع ارائه‌دهندگان رقابت طبیعی ایجاد می‌کند که هزینه‌ها را کاهش می‌دهد (0.49% تا 0.5%).



**محرمانگی**: بدون KYC، Interface 100% سمت مشتری (بدون انتقال داده‌های شخصی)، سازگار با مرورگر Tor.



غیر حضانتی: HTLC به‌طور ریاضی کنترل انحصاری بر وجوه شما را تضمین می‌کند. یا مبادله موفقیت‌آمیز است، یا بیت‌کوین‌های خود را پس می‌گیرید.



**منبع‌باز و قابل میزبانی شخصی**: کد عمومی قابل حسابرسی، قابل استقرار به‌صورت محلی برای حداکثر مقاومت در برابر سانسور.



### محدودیت‌ها



**نقدینگی محدود**: تعداد محدودی ارائه‌دهنده فعال (Boltz، Eldamar، MiddleWay بسته به دوره). مقادیر حداکثر ممکن است محدود باشد.



**زمان انقضا**: از ۲۴ ساعت تا ۴۸ ساعت. اگر تراکنش On-Chain قبل از انقضا تأیید نشود، بازیابی دستی لازم است.



**متمرکزسازی Interface**: اگرچه قابلیت میزبانی شخصی دارد، اما Interface رسمی بر روی GitHub Pages میزبانی می‌شود. اگر GitHub مخزن را سانسور کند، دسترسی از طریق swapmarket.github.io مسدود خواهد شد (راه‌حل: میزبانی شخصی).



**ردیابی‌های On-Chain**: اسکریپت‌های HTLC ممکن است با تحلیل پیشرفته Blockchain قابل شناسایی باشند.



## بهترین روش‌ها



### پیکربندی ایمن



**کلید نجات خود را دانلود کنید**: قبل از اولین مبادلات خود، کلید نجات خود را از تنظیمات دانلود کنید (به بخش اختصاصی بالا مراجعه کنید). این کلید منحصر به فرد برای تمام مبادلات آینده شما کار خواهد کرد و به شما امکان می‌دهد در صورت بروز مشکل، وجوه خود را بازیابی کنید.



**از مرورگر تور استفاده کنید**: برای حداکثر محرمانگی، از طریق مرورگر تور به SwapMarket دسترسی پیدا کنید تا IP شما Address مخفی بماند.



**در نظر گرفتن میزبانی شخصی**: برای کاربران فنی، اجرای نمونه SwapMarket خودتان وابستگی به دامنه رسمی GitHub Pages را از بین می‌برد.



### بهینه‌سازی تعویض



**مراقب Mempool باشید**: قبل از تعویض به Mempool.space مراجعه کنید. زمان‌هایی با فعالیت کم را انتخاب کنید تا هزینه‌های Mining را به حداقل برسانید.



**آدرس‌ها را بررسی کنید**: برای تعویض‌ها، به دقت Address دریافتی خود را بررسی کنید. از کپی و پیست استفاده کنید و ۵ کاراکتر اول و ۵ کاراکتر آخر را بررسی کنید.



**با مقادیر کم آزمایش کنید**: با حداقل مقدار مجاز (25,000 تا 50,000 Sats) شروع کنید. پس از تسلط بر فرآیند، به تدریج افزایش دهید.



**مستند کردن مبادلات خود**: شناسه هر مبادله، بازخرید Address و تاریخ انقضا را یادداشت کنید. این اطلاعات به پیگیری و بازیابی در صورت بروز مشکل فنی کمک می‌کند.



### استراتژی استفاده



**جریان نقدی خود را متعادل کنید**: از SwapMarket استفاده کنید تا تخصیص خود بین On-Chain (پس‌انداز، امنیت بلندمدت) و Lightning (هزینه‌های روزانه، پرداخت‌های فوری) را بر اساس نیازهای واقعی خود تنظیم کنید.



**محاسبه سودآوری**: برای نیازهای دائمی نقدینگی لایتنینگ، هزینه تجمعی تعویض‌های مکرر را با باز کردن مستقیم یک کانال لایتنینگ مقایسه کنید. SwapMarket برای تنظیمات یک‌باره عالی است، نه لزوماً برای جریان‌های بزرگ و منظم.



## SwapMarket در مقابل Boltz: تفاوت چیست؟



### بولتز: فناوری در مقابل خدمات



**Boltz فناوری متن‌باز** (`boltz-backend` در GitHub) است که مبادلات اتمی را از طریق HTLC بین Bitcoin، Lightning و Liquid پیاده‌سازی می‌کند.



**نقطه بحرانی**: تمامی ارائه‌دهندگان SwapMarket (Boltz Exchange، ZEUS Swaps، Eldamar، Middle Way) نسخه‌ای از بک‌اند Boltz را به‌صورت مستقل اجرا می‌کنند. بنابراین فناوری زیربنایی یکسان است. یک آسیب‌پذیری در بک‌اند Boltz می‌تواند به‌طور بالقوه تمامی ارائه‌دهندگان را تحت تأثیر قرار دهد، اما ماهیت متن‌باز سیستم امکان ممیزی توسط جامعه را فراهم می‌کند.



**Boltz Exchange** یک سرویس واحد است که توسط تیم Boltz اداره می‌شود، در حالی که **SwapMarket** چندین ارائه‌دهنده را که همگی از فناوری Boltz استفاده می‌کنند، گرد هم می‌آورد و یک محیط قیمت‌گذاری رقابتی ایجاد می‌کند.

**مزایای SwapMarket**: رقابت قیمتی، تنوع در نمونه‌های پشتیبان، مقایسه در زمان واقعی.



**گزینه‌های تکنولوژیکی** (سازگار با SwapMarket نیستند): Lightning Loop (Lightning Labs)، Muun Wallet، NLoop، Breez Wallet. این راه‌حل‌ها از پیاده‌سازی‌های خودشان از ساب‌مارین سواپ‌ها استفاده می‌کنند.



**توصیه**: از Boltz Exchange برای سادگی استفاده کنید یا از SwapMarket برای بهینه‌سازی هزینه‌ها از طریق رقابت استفاده کنید. هر دو از نظر ایمنی معادل هستند (HTLC غیرامانی).



## نتیجه‌گیری



SwapMarket با تجمیع چندین ارائه‌دهنده در یک Interface، مبادلات Bitcoin/Lightning را تسهیل می‌کند. معماری HTLC ماهیت غیرامانی مبادلات را تضمین می‌کند، عدم وجود KYC محرمانگی را حفظ می‌کند و کد متن‌باز قابل میزبانی خود، مقاومت در برابر سانسور را تقویت می‌کند.



رقابت بین ارائه‌دهندگان نرخ‌ها را بهبود می‌بخشد و منابع نقدینگی را چند برابر می‌کند. برای بهینه‌سازی مدیریت دو-Layer (صرفه‌جویی On-Chain، هزینه‌های Lightning)، SwapMarket ابزاری عملی است که حاکمیت مالی و محرمانگی را حفظ می‌کند.
