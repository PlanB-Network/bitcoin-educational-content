⚠️ **गंभीर सुरक्षा चेतावनी (7 अगस्त 2026):** BTCPay Server को प्रभावित करने वाली एक गंभीर भेद्यता का सक्रिय रूप से दुरुपयोग किया जा रहा है, जिससे धनराशि का नुकसान हो सकता है। अपने इंस्टेंस को तुरंत `Admin Dashboard > Server > Maintenance > Update` के माध्यम से **version 2.4.2** पर अपडेट करें, फिर जाँच लें कि फ़ुटर में `2.4.2` दिख रहा है। यदि आप तुरंत अपडेट नहीं कर सकते, तो अपना BTCPay Server बंद कर दें। अपडेट करने के बाद, आपको अपने macaroons और अपनी `macaroons.db` को भी पूरी तरह से नए सिरे से बनाना होगा, किसी भी अन्य Lightning बैकएंड की प्रमाणीकरण स्ट्रिंग्स को पूरी तरह से नए सिरे से बनाना होगा, और यदि आपने BTCPay Server के भीतर कोई हॉट on-chain वॉलेट बनाया था, तो उस धनराशि को स्थानांतरित करें और वॉलेट को फिर से बनाएँ। इंटीग्रेटर्स को NBXplorer को भी version 2.6.10 पर अपडेट करना चाहिए। स्रोत: [BTCPay Server 2.4.2 रिलीज़ नोट्स](https://github.com/btcpayserver/btcpayserver/releases/tag/v2.4.2)।

BTCPay सर्वर एक ओपन-सोर्स भुगतान प्रोसेसर है जो व्यापारियों और उपयोगकर्ताओं को लेनदेन प्रसंस्करण के लिए किसी तीसरे पक्ष पर निर्भर किए बिना Bitcoin भुगतान स्वीकार करने में सक्षम बनाता है। 2017 में लॉन्च किया गया, BTCPay सर्वर ई-कॉमर्स साइटों के लिए Bitcoin भुगतान एकीकरण समाधान प्रदान करता है, जिसमें हार्डवेयर वॉलेट, बिलिंग और अकाउंटिंग टूल के लिए समर्थन, साथ ही Lightning Network के साथ संगतता जैसी उन्नत सुविधाएँ हैं। इसका विकास निकोलस डोरियर द्वारा बिटपे की कार्रवाइयों के जवाब में शुरू किया गया था, जिसने उनके अनुसार, अपने उपयोगकर्ताओं को SegWit2x को अपनाने के लिए प्रेरित करके उन्हें गुमराह किया था, जिसे कंपनी ने गलती से "असली" Bitcoin मान लिया था। इस विरोध को अगस्त 2017 में निकोलस डोरियर के एक अब-प्रसिद्ध ट्वीट में समाहित किया गया था:


> "यह झूठ है, मेरा तुम पर से भरोसा टूट गया है, मैं तुम्हें बेकार कर दूंगा".
