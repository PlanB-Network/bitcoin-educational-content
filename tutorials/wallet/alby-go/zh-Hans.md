## 🔌 连接钱包


Alby Go 可通过 NWC（Nostr Wallet Connect）密码连接到支持闪电的节点或钱包。您可以连接一个或多个钱包，方便切换。

步骤：

1.打开 Settings → Wallets → Connect a Wallet

2.扫描二维码或粘贴 NWC Connection Secret（例如：nostr+walletconnect://...）

3.为连接给一个自定义名称


连接后，您的钱包或节点就可以通过 Alby Go 发送和接收比特币闪电付款。


✅ 提示：您可以连接多个钱包，可随时切换。




## 发送比特币


通过闪电网络发送比特币：

1.点击黄色的**SEND**按钮。

2.从以下选项中选出其中一个：


 - 扫描闪电发票二维码
 - 从剪贴板粘贴闪电发票
 - 手动输入闪电地址


您还可以从 Address Book 中选择接收者，您可以在此保存闪电地址，方便再次使用。




## 接收比特币

使用 Alby Go 接收比特币的步骤如下：

1.点击黄色的**RECEIVE**按钮。

2.从以下选项中选出其中一个：


 - 分享闪电地址
 - 选择 "Amount" 以生成可自定义金额的闪电发票
 - 点击 "Redeem" 以扫描 LNURL 提取二维码


为方便发送者使用，系统同时提供二维码与发票字符串两种方式。
