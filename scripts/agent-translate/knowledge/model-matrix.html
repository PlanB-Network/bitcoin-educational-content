Translation model matrix — courses/btc101/

Best agent model + thinking effort per language · Opus 4.8/4.5 · Sonnet 5/4.5 · GPT-5.5

29 target languages (30 .md files; en.md is the source) · Bitcoin educational content, technical + pedagogical prose · compiled 2026-07-03

Two forces govern every row. (1) Reasoning/thinking raises translation quality — long chain-of-thought lifts adequacy, fluency and literary nuance (DRT, ACL 2025), and matters most for low-resource and morphologically rich targets. (2) Reasoning also blows up cost: on one standardized multilingual-translation run, a "cheap" model burned $398 vs $75 for Opus at adaptive thinking on the same task. So effort is dialed per tier, not maxed everywhere. Across 29 files × ~130 KB, prefer adaptive/self-verifying passes over blanket xhigh.

Model profiles

Opus 4.8$5 / $25 · 1M ctx · May 2026

Flagship reliability. Self-verification (from 4.7) + xhigh effort + adaptive thinking. ~4× less likely than 4.7 to pass its own flaws. Best when terminology consistency across a 130 KB doc and hardest languages matter. Fast mode $10/$50 at 2.5×.

Sonnet 5$3 / $15 (intro $2/$10) · 1M ctx · Jun 2026

Near-Opus, half price. Wins European-language naturalness vs GPT-5.5 and slightly beats Opus 4.8 on knowledge work. The value pick for Tier A/B.

GPT-5.5reasoning effort low→high · Apr 2026

Strongest raw multilingual: ~85% MMMLU overall, best per-language on CJK / Arabic / Hindi (ZH 86, JA 84, KO 83, HI 78). More literal — can feel stilted in European prose. Reasoning cost can spike; cap effort.

Opus 4.5 / Sonnet 4.5$5/$25 · $3/$15 · 2025

Prior gens, still available. Opus 4.5 = the efficiency release (76% fewer tokens) — a cheaper-effective fallback. Sonnet 4.5 superseded by Sonnet 5; use only if pinned.

How to read the picks. Rankings synthesize (a) each language's resource tier & script complexity and (b) measured model profiles — Sonnet 5 for European naturalness, GPT-5.5 for raw CJK/Indic accuracy, Opus 4.8 for self-verification & terminology consistency on the hardest targets. [INFERENCE] No public head-to-head benchmark exists for all 29 languages against these exact models; treat picks as evidence-based priors, not measured per-language scores. For Tier D (si, sw, rn) pair any model with a termbase + human review, and consider an NLLB-200 draft.

Operational recommendation

For the whole btc101 run, a single sensible default: Sonnet 5 · medium for Tier A/B and Opus 4.8 · high/xhigh for Tier C/D — GPT-5.5 · high as the swap-in for CJK (ja ko zh-Hans zh-Hant), hi, fa, th, vi. Always: (1) a fixed Bitcoin glossary/termbase (Bitcoin, block, hash, private key, seed, node…) injected in-prompt; (2) preserve Markdown structure, links, code fences, image paths; (3) a second self-verification pass against source for numbers, terms and untranslated segments; (4) cap reasoning effort — measure real token cost on one file before fanning out to 29.
