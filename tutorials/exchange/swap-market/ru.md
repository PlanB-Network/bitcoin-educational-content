Перевод средств между Bitcoin On-Chain и Lightning Network обычно требует либо ручного открытия каналов Lightning (что технически сложно и дорого), либо использования централизованных своп-платформ с KYC. SwapMarket предлагает альтернативу: Trustless атомарные свопы через конкурентных провайдеров без KYC.



Инновации: несмотря на то, что провайдеры являются посредниками, HTLC (*Hash Time Locked Contracts*) математически гарантирует, что ваши средства остаются под вашим контролем. Объединение нескольких провайдеров (Boltz, ZEUS Swaps, Eldamar, Middle Way) создает ценовую конкуренцию. Веб Interface с открытым исходным кодом и возможностью самостоятельного хостинга.



## Что такое SwapMarket?



Агрегатор с открытым исходным кодом, запущенный в 2024 году, SwapMarket функционирует как компаратор поставщиков свопов Bitcoin/Lightning. Пользователь мгновенно сравнивает условия (комиссии, ликвидность, лимиты) и выбирает оптимального поставщика.



### Техническая архитектура



**Фронтенд клиентской части**: 100% клиентское приложение (Fork Boltz Web App), размещенное на GitHub Pages. Код запускается в браузере без бэкенд-сервера. История хранится локально (куки/кэш). Публичный и проверяемый исходный код.



**Открытие провайдера** : Hard-кодированный список в `src/configs/Mainnet.ts`. Новые провайдеры добавляются через Pull Request или по электронной почте.



**Независимые бэкенды**: Каждый поставщик работает с собственным бэкендом Boltz. Interface запрашивает API в режиме реального времени, чтобы мгновенно сравнивать котировки.



**HTLC Атомарные свопы**: Контракты Hash с временной блокировкой гарантируют атомарность: либо своп исполняется, либо каждая сторона возвращает свои средства. Риск контрагента математически исключен.



### Философия



SwapMarket снижает централизацию, создавая конкуренцию между провайдерами за комиссии и ликвидность. Отсутствие KYC, самодостаточный код с открытым исходным кодом, множество независимых операторов, чтобы избежать единых точек отказа.



## Основные характеристики



### Рынок поставщиков



Interface отображает всех активных провайдеров: название провайдера, применяемые комиссии (процентные и/или фиксированные), минимальные/максимальные доступные суммы и поддерживаемые типы свопов. Приложение напрямую запрашивает API каждого провайдера, указанного в конфигурационном файле, чтобы получить котировки в режиме реального времени. Конкуренция между провайдерами гарантирует оптимальные ставки, как правило, около 0,5 % для стандартных свопов.



### Двунаправленные свопы



**Обмен (On-Chain → Lightning)**: Конвертируйте BTC On-Chain в сатоши Lightning. Вариант использования: питание мобильного Wallet Lightning, получение входящей мощности на узле или мгновенная ликвидность.



**Обмен (Lightning → On-Chain)**: Конвертирует сатоши Lightning в BTC On-Chain. Использование: сброс Wallet Lightning в хранилище Cold или восстановление баланса ликвидности между слоями.



### Безопасность и восстановление



**Trustless Атомные свопы: HTLC гарантирует, что либо Exchange будет выполнен в полном объеме, либо каждая сторона вернет свою долю. Риск контрагента математически исключен.



**Механизм выкупа**: Каждый своп имеет срок действия (TIMELOCK). Если своп не удался, средства автоматически возвращаются после истечения срока действия. У пользователя всегда остается возможность вернуть свои биткоины.



** Ключи восстановления**: SwapMarket позволяет экспортировать ключи восстановления для текущих свопов. В случае возникновения проблем эти ключи можно использовать для завершения или отмены свопа с любого устройства.



## Установка и доступ



### Interface web



SwapMarket не требует установки. Доступ осуществляется через браузер по адресу https://swapmarket.github.io. Для максимальной конфиденциальности используйте Brave, Firefox с расширениями против слежки или LibreWolf. Для обеспечения сетевой анонимности рекомендуется использовать браузер Tor.



Регистрация, электронная почта или проверка личности не требуются.



### Самостоятельный хостинг (опционально)



Для технических пользователей, желающих избавиться от зависимости от официального домена GitHub Pages, SwapMarket можно запустить локально:



**Via npm** :


```
git clone https://github.com/SwapMarket/swapmarket.github.io.git
cd swapmarket.github.io
npm install
npm run dev
```



**Via Docker** :


```
docker run -p 3000:80 ghcr.io/swapmarket/swapmarket:latest
```



Приложение будет доступно по адресу `http://localhost:3000`. Самостоятельный хостинг гарантирует полный контроль над Interface, исключает риск цензуры официального домена и позволяет проверять исходный код перед выполнением.



### Начальная конфигурация



**Wallet Lightning**: Убедитесь, что у вас есть действующий Wallet Lightning (Phoenix, Zeus, BlueWallet и т.д.). При подмене вы заплатите generate за Lightning Invoice. За подмену вы заплатите Lightning Invoice.



**Wallet On-Chain**: Для своп-ин вам понадобится Wallet Bitcoin On-Chain для отправки средств. Для своп-аутов подготовьте Bitcoin, получающий Address.



**Опциональная конфигурация**: SwapMarket сохраняет историю свопов и предпочтения в cookies браузера. Создание учетной записи не требуется.

## Создание свопа шаг за шагом



### Обмен: Молния → Bitcoin



В этом первом примере показано, как конвертировать сатоши Lightning в биткоины On-Chain.



**Шаг 1: Подмена конфигурации



На главной странице выберите форму обмена:




- LIGHTNING** (верхнее поле): Введите сумму, которую вы хотите отправить в Sats Lightning (пример: 30 000 Sats)
- Bitcoin** (нижнее поле): Сумма, которую вы получите, автоматически отображается после вычета комиссионных (пример: Sats 29 320)



В нижнем поле вставьте свой **получатель Bitcoin Address**, где вы хотите получить средства. Внимательно проверьте этот Address.



Поставщиком по умолчанию обычно является Boltz Exchange. Сетевые тарифы и тарифы провайдера четко отображаются.



![Configuration swap-out](assets/fr/03.webp)



**Шаг 2: Выбор поставщика**



Нажмите на выпадающее меню провайдера (по умолчанию: "Boltz Exchange"), чтобы отобразить всех доступных провайдеров ликвидности.



Откроется модальное окно, в котором будет показана сравнительная таблица:




- Статус**: Индикатор Green, если провайдер активен
- Псевдоним**: Имя поставщика (Boltz Exchange, Middle Way, Eldamar, ZEUS Swaps)
- Плата**: Плата, взимаемая поставщиком услуг (обычно от 0,49% до 0,5%)
- Максимальный своп**: Максимальная сумма, принимаемая для свопа



Сравните тарифы и максимальные суммы, а затем выберите подходящего поставщика.



**Обратите внимание**: В окне выбора поставщика Interface не отображаются **минимальные суммы** для каждого поставщика. Эта информация появляется только в Interface при создании свопа, после выбора поставщика. Минимальные и максимальные суммы могут отличаться у разных провайдеров и могут меняться со временем. **Всегда проверяйте эти лимиты во время свопа**: если сумма, которую вы хотите обменять, выходит за рамки лимитов провайдера, вы можете выбрать другого, более подходящего для вашей операции.



![Sélection du provider](assets/fr/04.webp)



**Шаг 3: Создание свопа и молниеносная** оплата



Нажмите на желтую кнопку **"CREATE ATOMIC SWAP "**. SwapMarket отправит вам generate **Lightning Invoice** (BOLT11) для оплаты с вашего Wallet Lightning.



На странице отображается :




- Идентификатор свопа**: Уникальный идентификатор свопа (пример: J4ymFIMVR6Hm)
- Статус**: "swap.created" (своп создан, ожидает оплаты)
- QR-код**: Отсканируйте его с помощью вашего Wallet Lightning
- Invoice Lightning**: Строка символов, начинающаяся с "lnbc" (пример: lnbc300u1p50whiv...gn5dk2szgqkvfkzc)



Оплатите этот Invoice с вашего Wallet Lightning (Phoenix, Zeus, BlueWallet и т.д.). На экране отображается точная сумма платежа (пример: 30 000 Sats).



![Paiement Lightning](assets/fr/05.webp)



**Шаг 4: Подтверждение и принятие**



После подтверждения платежа Lightning SwapMarket мгновенно получает ваш платеж, а провайдер транслирует транзакцию Bitcoin на ваш Address.



Статус изменится на **"Invoice.settled "** (Invoice оплачен), и появится подтверждающее сообщение.



Ваши биткоины On-Chain будут доступны сразу же после подтверждения транзакции (обычно в течение от нескольких минут до нескольких часов, в зависимости от комиссии Mining, выбранной провайдером).



![Confirmation swap-out](assets/fr/06.webp)



Вы можете нажать на **"OPEN CLAIM TRANSACTION "**, чтобы просмотреть транзакцию Bitcoin в проводнике Blockchain.



### Подмена: Bitcoin → Молния



Второй пример показывает, как конвертировать биткоины On-Chain в сатоши Lightning.



**Шаг 1: Подмена конфигурации



На главной странице выберите форму обмена:




- Bitcoin** (верхнее поле): Введите сумму, которую вы хотите отправить в Sats Bitcoin (пример: 63 400 Sats)
- LIGHTNING** (нижнее поле): Сумма, которую вы получите, автоматически отображается после вычета комиссионных (пример: 62 884 Sats)



В нижнее поле вставьте Lightning** Invoice (BOLT11), сгенерированный из вашего Wallet Lightning, или используйте LNURL Address, если ваш Wallet поддерживает его.



![Configuration swap-in](assets/fr/07.webp)



**Шаг 2: Проверка ключа спасения**



После нажатия на **"CREATE ATOMIC SWAP "** появится модальное окно, в котором вам будет предложено подтвердить ваш ключ спасения.



![Modal Rescue Key](assets/fr/08.webp)



**Boltz Rescue Key**: Поскольку вы уже загрузили ключ восстановления во время первоначальной настройки (см. предыдущий раздел), нажмите на кнопку **"VERIFY EXISTING KEY "**, чтобы импортировать сохраненный ключ.



Выберите ранее загруженный файл Rescue Key. После успешной проверки Interface автоматически переходит к следующему шагу.



**Шаг 3: Bitcoin** депозит Address



SwapMarket теперь генерирует **уникальный Bitcoin Address**, содержащий HTLC Contract, связанный с вашим Lightning Invoice.



На странице отображается :




- Идентификатор подмены**: Уникальный идентификатор (пример: 1kGmB6JyGqU4)
- Статус** : "Invoice.set" (Invoice установлен, ожидает оплаты Bitcoin)
- QR-код**: Bitcoin депо Address
- Bitcoin** Address: Обычно начинается с "bc1p..." (пример: bc1p5mvtwxapjkds...9d4n9f)
- Предупреждение желтого цвета** : "Убедитесь, что ваша сделка подтверждена в течение ~24 часов после создания этого свопа!"



Этот период ~24 часа является **таймаутом** для HTLC Contract. Если ваша транзакция Bitcoin не будет подтверждена в течение этого времени, своп не состоится, и вам придется использовать свой ключ Rescue Key для восстановления средств.



![Adresse de dépôt Bitcoin](assets/fr/09.webp)



Вы можете скопировать Address, нажав на кнопку **"Address"**, или отсканировать QR-код прямо с вашего Wallet On-Chain.



**Шаг 4: Отправка биткоинов**



Со своего Wallet Bitcoin On-Chain отправьте **точно** указанную сумму (например, 63 400 Sats) на сгенерированный Address.



**Важно**: Используйте соответствующие комиссии Mining, чтобы гарантировать быстрое подтверждение. Если комиссия слишком мала и транзакция остается в Mempool дольше таймаута (~24 часа), своп будет неудачным.



После отправки сделки SwapMarket обнаруживает, что она находится в Mempool, и отображает :




- Статус** : "transaction.Mempool"
- Сообщение**: "Сделка находится в Mempool - ожидание подтверждения для завершения свопа"



![Transaction en mempool](assets/fr/10.webp)



**Шаг 5: Подтверждение и молниеносный** прием



Как только транзакция Bitcoin получает первое подтверждение, провайдер автоматически оплачивает ваш Lightning Invoice. Вы мгновенно получаете сатоши на свой Wallet Lightning.



Статус меняется на **"transaction.claim.pending "**, затем отображается подтверждающее сообщение:



![Confirmation swap-in](assets/fr/11.webp)



Ваши сатоши "Молния" сразу же становятся доступны в вашем Wallet.



## Преимущества и ограничения



### Преимущества



**Конкуренция тарифов**: Объединение провайдеров создает естественную конкуренцию, снижая тарифы (от 0,49% до 0,5%).



**Конфиденциальность**: Отсутствие KYC, Interface 100% клиентская часть (без передачи персональных данных), совместимость с Tor Browser.



**Без опеки**: HTLC математически гарантирует исключительный контроль над вашими средствами. Либо обмен пройдет успешно, либо вы получите свои биткоины обратно.



**Open-source self-hostable**: проверяемый публичный код, развертываемый локально для максимальной устойчивости к цензуре.



### Ограничения



**Ограниченная ликвидность**: Ограниченное количество активных провайдеров (Boltz, Eldamar, MiddleWay в зависимости от периода). Максимальные суммы могут быть ограничены.



**Время истечения**: Время истечения от 24 до 48 часов. Если транзакция On-Chain не подтверждена до истечения срока действия, требуется ручное восстановление.



**Централизация Interface**: Несмотря на возможность самостоятельного хостинга, официальный Interface размещен на GitHub Pages. Если GitHub подвергнет репо цензуре, доступ через swapmarket.github.io будет заблокирован (решение: самостоятельный хостинг).



**Следы On-Chain**: Скрипты HTLC потенциально могут быть идентифицированы с помощью продвинутого анализа Blockchain.



## Лучшие практики



### Безопасная конфигурация



**Загрузите ключ спасения**: Перед первым обменом загрузите ключ спасения из Настроек (см. специальный раздел выше). Этот уникальный ключ будет работать для всех ваших будущих обменов, позволяя вам восстановить средства в случае возникновения проблем.



**Используйте браузер Tor**: Для обеспечения максимальной конфиденциальности заходите на SwapMarket через браузер Tor, чтобы скрыть свой IP Address.



**Рассмотрите возможность самостоятельного хостинга**: Для технических пользователей запуск собственного экземпляра SwapMarket устраняет зависимость от официального домена GitHub Pages.



### Оптимизация подкачки



**Следите за Mempool**: Проверяйте Mempool.space перед заменой. Выбирайте время низкой активности, чтобы минимизировать затраты на Mining.



**Проверьте адреса**: При обмене тщательно проверьте адрес получателя Address. Используйте копирование и вставку и проверяйте первые 5 и последние 5 символов.



**Протестируйте небольшие количества**: Начните с минимально допустимого (25 000 - 50 000 Sats). Постепенно увеличивайте количество, когда освоите процесс.



**Документируйте свои свопы**: Записывайте идентификатор каждого свопа, дату погашения Address и дату истечения срока действия. Эта информация облегчает отслеживание и восстановление в случае технических проблем.



### Стратегия использования



**Сбалансируйте свой денежный поток**: Используйте SwapMarket, чтобы регулировать распределение между On-Chain (сбережения, долгосрочная безопасность) и Lightning (ежедневные расходы, мгновенные платежи) в соответствии с вашими реальными потребностями.



**Рассчитайте рентабельность**: Для постоянных потребностей в ликвидности Lightning сравните совокупную стоимость повторных свопов с открытием канала Lightning напрямую. SwapMarket отлично подходит для разовых корректировок, но не обязательно для больших регулярных потоков.



## SwapMarket против Boltz: В чем разница?



### Больц: Технология против сервиса



**Boltz - это технология с открытым исходным кодом** (`boltz-backend` на GitHub), которая реализует атомарный обмен через HTLC между Bitcoin, Lightning и Liquid.



**Критический момент**: Все провайдеры SwapMarket (Boltz Exchange, ZEUS Swaps, Eldamar, Middle Way) развертывают свой собственный экземпляр бэкенда Boltz. Таким образом, базовая технология идентична. Уязвимость в бэкенде Boltz потенциально может затронуть всех провайдеров, однако открытый исходный код системы позволяет проводить аудит сообществом.



**Boltz Exchange** - это единый сервис, управляемый командой Boltz, а **SwapMarket** объединяет несколько провайдеров, использующих технологию Boltz, создавая конкурентную ценовую среду.



Более подробную информацию вы найдете в наших руководствах по обмену Boltz и Zeus:



https://planb.network/tutorials/exchange/centralized/boltz-34ad778e-6dc7-41c2-8219-e11e3361a43d

https://planb.network/tutorials/exchange/centralized/zeus-swap-b6732907-b5d8-43ea-85e3-9dcd6e6abe47

**Преимущества SwapMarket**: Ценовая конкуренция, диверсификация бэкэнд-инстансов, сравнение в реальном времени.



**Технологические альтернативы** (не совместимые со SwapMarket): Lightning Loop (Lightning Labs), Muun Wallet, NLoop, Breez Wallet. Эти решения используют собственные реализации подводных свопов.



**Рекомендация**: Используйте Boltz Exchange для простоты или SwapMarket для оптимизации затрат за счет конкуренции. Оба варианта эквивалентны по безопасности (HTLC не требует особого ухода).



## Заключение



SwapMarket способствует обмену Bitcoin/Lightning, объединяя нескольких провайдеров в один Interface. Архитектура HTLC гарантирует некастодиальный характер свопов, отсутствие KYC сохраняет конфиденциальность, а самодостаточный код с открытым исходным кодом усиливает устойчивость к цензуре.



Конкуренция между провайдерами повышает ставки и увеличивает источники ликвидности. Для оптимизации управления двумя Layer (экономия On-Chain, расходы на Lightning) SwapMarket - это практичный инструмент, сохраняющий финансовый суверенитет и конфиденциальность.
