## 安装 Breez POS



Breez POS 是 Breez Wallet 提供的一项自我保管服务。这项服务的作用是使商家能够通过 Bitcoin 收款，同时保持简单的 Interface，这与各种闪电钱包非常相似。Breez POS 可在 [Google Play Store](https://play.google.com/store/apps/details?id=com.breez.client) (Android) 和 [App Store](https://apps.apple.com/app/breez-lightning-client-pos/id1463604142) (iOS) 下载平台上下载。

## 使用 Breez POS



在本教程中，我们将重点介绍 "*销售点*"部分，帮助您了解如何将其整合为企业的一种支付手段。



销售点是 Breez 产品组合不可分割的一部分，主要依靠 Lightning Network 收款。



在 "*销售点*"菜单中，您可以找到用于收款的 Interface。它分为两个部分：



### 直接借记



第一部分是直接借记键盘。当您知道客户的总购买量，或在业务中不需要固定的产品目录（如自由职业者服务）时，Interface 就能方便地收取单笔付款。



![keyboard](assets/fr/02.webp)



要首次使用 Breez POS，您需要支付超过 2500 个卫星币（按现在的 Exchange 汇率计算，约合 3 欧元）。这笔钱只在您首次提现时支付，是创建支付通道的费用，这样您就可以与其他 Lightning Network 节点通信并收发卫星币。



![channel_fee](assets/fr/03.webp)


### 产品目录



第二部分是产品目录。如果您有一个带预定义价格的产品目录，Interface 就是您的理想选择。在这里，您可以预先配置产品，然后将其用于 generate 发票，以提高现金收据的可追溯性。



![items](assets/fr/04.webp)



您可以点击 "**加**"按钮，然后为该项目定义名称、价格和标识符，从而手动配置 Interface 中的每个项目。



![add_items](assets/fr/05.webp)



然后，您就可以添加并定义其数量，以收取相关付款。



当您的商品目录比较大时，逐一添加商品可能会变得复杂。为此，在 "**首选项">"销售点设置 "**部分的 "商品列表 "菜单中，您可以自动从 CSV 文件导入和导出商品列表。



![import](assets/fr/07.webp)



在同一部分，您可以定义Lightning发票的有效期。从现在起，对于您的所有发票，您的客户有`N`秒的时间付款，否则您就必须重新生成新的 Lightning Invoice。



![invoice_time](assets/fr/08.webp)



作为管理者，您可以通过添加密码来加强比特币的安全性，所有从 Wallet 支付的款项都需要输入密码。当您不是唯一管理出口的人时，这项功能尤其有用。



![manager](assets/fr/09.webp)



在**交易**菜单中，您可以找到您已收取的所有付款的列表。您还可以点击**日历**按钮，过滤特定时间段内的结果。



![transactions](assets/fr/10.webp)



您还可以点击**文件**按钮，查看每日销售摘要和收款总额。



![summary](assets/fr/11.webp)
